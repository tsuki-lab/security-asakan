セキュリティ朝刊

11月1日（日）の朝刊

今日のひとこと：会員登録しているサービスから「情報が漏れた」と連絡が来たら、メールのリンクは開かず、公式サイトのお知らせを自分で開いて確かめてください。

1先週の大きな漏えい、新しい発表はまだありません。使っていた人は今日確認を

阪急・阪神百貨店の予約サイト、ニフティ、チケット購入サービス「GETTIIS」、So-net・plala などの会員情報の漏えいは、新しい発表が今朝は見つかっていません。

いずれも原因などは調査中で、会社から会員へ順にメールで連絡が届いています。週末は、便乗した偽のメール・SMS が増えやすい時期です。メールに書かれたリンクからではなく、いつも使っている公式サイトやアプリから、お知らせを確認してください。

みんながやること
  • 使ったことがあるサービスは、公式サイトのお知らせを自分で開いて確かめる
  • GETTIIS や So-net のメールを使っていた人は、パスワードを変える。同じパスワードを使い回している他のサービスも変える
  • カードの利用明細に身に覚えのない請求がないか、ときどき見る

2医療従事者向けの予約サービス「エンタッチ」が、ランサムウェアで情報流出

犯罪グループに会社のシステムへ入られ、データを盗まれたうえで脅される「ランサムウェア」の被害が、また一件公表されています。

エンタッチ株式会社が10月19日に発表しました。10月9日に侵入され、13日に気づいたとのことです。医療従事者の名前・勤め先の医療機関・都道府県のほか、予約のときに入力された電話番号やメールアドレスなどが流出しています。件数は調査中です。会社はパスワードの強制変更などを行ったと説明しています。

みんながやること
  • このサービスで予約をしたことがある人は、会社からの連絡を確認する
  • 見覚えのない電話・メールには、折り返さず、リンクも開かない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Rust：webpki-roots 1.0.9 は eMudhra のルートを信頼したまま

  • Rust ユーザーフォーラムの 10/28 の投稿による。1.0.9（7/18 公開）は emSign のルートを含む。1.0.10（10/19）で emSign ECC Root CA – G3 を、1.0.11（10/23）で emSign Root CA – C1 と emSign ECC Root CA – C3 を削除。
  • やること：cargo update -p webpki-roots で 1.0.10 以上（できれば 1.0.11）に。=1.0.9 の固定があれば外す。rustls-webpki は 0.103.16 以上、webpki-root-certs は 1.0.10 以上。cargo audit で RUSTSEC-2026-0381 / 0382 / 0383 を確認。ルート証明書を自前で同梱しているなら emSign で検索する。

2. エンタッチ：ランサムウェア（10/19 発表）

  • 10/9 侵入、10/13 発覚。ソフトウェアへのセキュリティパッチ適用、アクセスログの保全、パスワードの強制変更、外部専門機関による調査を実施と説明。侵入経路は記事に記載なし。件数は調査中。（ScanNetSecurity の記事を読んだ。会社の原文は未読）

3. 続報なし：PHP2Shell／Brotli／eMudhra／LiteLLM／各社の漏えい

  • PHP2Shell（CVE-2026-109618 / 109619）：修正版は 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35。8.1 以前は公式の修正なし。CVE-2026-115560 の回避策は session.upload_progress.enabled=0。
  • Brotli の C 実装（CVE-2026-111497）：1.2.1 / 1.1.1 / 1.0.10。Node.js は 22.23.4 / 24.22.1 / 26.12.1。
  • eMudhra：Chrome の G3 削除（10/27 PT の予定）後の追加の発表、Apple の /etc/ssl/cert.pem を直す macOS 更新は、今朝も確認できなかった。手順は Apple のサポート記事 149555。発行元に emSign / eMudhra があれば別の CA で取り直す。
  • LiteLLM 1.107.0（マルウェア版。安全な版は 1.106.2）、npm / PyPI の新しい侵害、CISA KEV の新しい追加：今朝の検索では確認できなかった（確認できなかっただけで、無いとは限らない）。
  • So-net・plala・ニフティ・GETTIIS・H2O の侵入経路は引き続き調査中。管理系の社内システムと共有アカウントの多要素認証・IP 制限・権限の棚卸しは、前号の示唆のとおり。
