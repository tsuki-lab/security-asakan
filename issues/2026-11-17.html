セキュリティ朝刊

11月17日（火）の朝刊

今日のひとこと：同じパスワードをいくつものサービスで使っている人は、大事なもの（メール・ネット銀行・買い物）から別々のパスワードに変えてください。流出が続いていて、1か所から漏れると全部に入られます。

1多くの会社のサイトの裏側で使われるサービスから、情報が流出

会社のサイトやアプリでお客さんの動きを分析する「KARTE」というサービスが不正アクセスを受け、利用している会社の顧客情報の一部などが持ち出されました。

運営するプレイドの11月16日の発表によると、持ち出されたのは KARTE に登録された約7万9千件のメールアドレス、ほかのサービスとつなぐための「合い鍵」、利用企業が取り込んだお客さんの情報の一部です。件数や中身はまだ調べている最中です。KARTE は11月13日から止まっていて、いくつかのサイトでお知らせの表示などが動いていない可能性があります。

みんながやること
  • よく使うお店や会社から「情報流出のお知らせ」が届いたら、メールのリンクではなく公式サイトで内容を確かめる
  • 流出をきっかけにした「確認のため入力を」というメール・SMS は開かない

2靖国神社の通販サイトから約1万4500件。パスワードの手がかりも

靖国神社のお守りなどを扱う通販サイトが攻撃を受け、利用者の情報が流出しました。

流出したのは氏名、メールアドレス、パスワードを変換した値などで、神社は元のパスワードを割り出されるおそれがあるとしています。サイトは10月28日から止まっていて、対象の人にはメールで連絡するとのことです。

みんながやること
  • このサイトを使ったことがあり、同じパスワードをほかでも使っている人は、ほかのサービスのパスワードを変える
  • 神社を名乗るメールが来ても、リンクは開かず公式サイトから確かめる

3スーパーコンピューター「富岳」に不正アクセス。利用者のログイン用の鍵が持ち出される

理化学研究所のスーパーコンピューター「富岳」が不正アクセスを受け、11月14日から止まっています。

利用者への連絡によると、一部の利用者がログインに使う「鍵」や認証の情報が外に持ち出されました。研究データへの影響は調査中で、再開時期は決まっていません。職場や学校のシステムでも同じことが起きうるので、「パスワードを変えて」という連絡が来たときの確かめ方を知っておくと安心です。

みんながやること
  • 職場や学校から「パスワードを変えて」と連絡が来たら、メールのリンクではなく、いつものログイン画面や担当部署に確かめてから変える
  • 仕事用と私用で同じパスワードを使わない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. KARTE（プレイド）：漏えい内容を公表（11/16）。連携用の認証情報を至急無効化

  • 漏えいを確認：KARTE のアカウント登録メールアドレス 79,249件、外部サービス連携用の認証情報（シークレットキー・アクセストークン等、件数調査中）、「紐付けテーブル」機能などで利用企業が取り込んだ顧客情報の一部（件数調査中）。
  • 原因：サーバーの脆弱性を突かれてシステム・DB の接続用認証情報を盗まれ、アカウントを乗っ取られて DB からデータを持ち出され、管理画面にも侵入された。11/13 未明に発生、8:59 検知、15:23 ごろ封じ込め完了。再開時期は未定。
  • やること：外部連携を設定していれば該当の認証情報を無効化し、連携先（MA・CRM・広告・データ基盤など）のアクセスログで不審な書き換え・読み出しを確認。紐付けテーブルに入れた顧客情報の項目を洗い出し、個人情報保護委員会への報告や本人通知の要否を判断。KARTE の登録メールアドレス宛の偽メールに注意。

2. npm @ethersphere/bee-js 13.3.0 と Swarm Desktop 0.56.2 に裏口（11/9）

  • bee-js 13.3.0 は 11/9 00:09〜01:25 UTC（約75分）公開。安全な版は 13.2.0。Swarm Desktop 0.56.2 は約8.5時間公開、安全な版は 0.56.3。プロジェクト自身の CI・署名の仕組みから出たため、署名・来歴は正しかった。
  • postinstall で api.frameworkmetrics[.]xyz から追加のコードを取り、Swarm のウォレット鍵を盗む。Linux / macOS は ~/.solidity/ に Go の裏口（systemd solidity-langsupport-runner.service / LaunchAgent com.solidity.langsupport.runner）、Windows は ScreenConnect（ScreenConnect Client (5cbe79c9c25524df)）。
  • やること：ロックファイル・キャッシュ・社内レジストリ・CI のログで 13.3.0 を探す（swarm-cli・bee-dashboard などのゆるい版指定経由も）。入っていれば端末・ランナーは侵害扱いで、別の端末から鍵・トークンを交換。更新や入れ直しでは裏口は消えない。

3. AI エージェントが公開中の AI アプリから API キーを集める（Amazon の報告）

  • 標的：LLM の中継（One API・New API・LiteLLM など）と AI アプリの作成ツール（Dify・FastGPT・Langflow・RAGFlow・Open WebUI・LobeChat・Ollama）。攻撃ツール ARTEX を使い、見つけたキーを検証して共有の束に足す。
  • 入口：Langflow CVE-2025-3248（1.3.0 未満、CISA KEV）、RAGFlow CVE-2026-28797（0.24.0 以前、0.25.0 で修正）、One API の認証回避（修正版の記載なし）、LiteLLM の既定の master key、作りかけのインストール、認証のない管理 API、SSRF でのクラウドのメタデータ、JS・ソースマップ・.env に残った秘密。
  • やること：AI アプリと推論の入口を本番扱いにし、既定の認証情報を変え、管理画面を外に出さない。Cloudflare の API トークンには期限と IP 制限を付け、cfut_ で始まるトークンの漏れを探す。artex-* という名前の Worker スクリプトがないか確認。AI の利用料金の急増を監視。

4. 「富岳」：一部利用者の SSH 秘密鍵・認証情報が持ち出された

  • 11/12 に利用者認証のシステムへ不審な通信、11/14 4:30 に外部からのアクセスを遮断して運用停止。ホームディレクトリなどのファイルが読み出された。原因・経路は調査中。
  • 共有の計算機・踏み台に置いた秘密鍵は持ち出されうる前提で、そこで使った鍵を交換し、同じ鍵を登録したほかのサーバー・Git ホスティングからも外す。鍵にはパスフレーズを付け、可能ならハードウェアキーや短期の証明書に。

5. Linux「NoisyTCP」・Windows「SignDrop」・N-central

  • Linux カーネル CVE-2026-99288（NoisyTCP）：細工した TCP パケットで認証なしにカーネルを落とせる（コード実行はなし、競合の窓は狭い）。ほぼすべてのディストリビューションが対象で、修正はメインラインに入っている。各ディストリの更新を当てて再起動。
  • Windows CLFS の「SignDrop」：一般ユーザーから SYSTEM を取る攻撃コードが公開、CVE 未付番・未修正（Microsoft は調査中）。
  • N-able N-central「4EverAble2Shell」CVE-2026-114406：悪用あり（21 台が侵害）。CISA KEV に 11/13 追加の UnrealIRCd CVE-2026-114713（6.2.7.1 で修正）と Check Point CVE-2026-123039 の連邦機関向けの期限は 11/16 だった。

6. 続いている話

  • eMudhra：emSign Root CA - G1 の新規証明書の期限（2026-11-16 23:59:59 UTC、Chrome・Firefox）は過ぎた。Microsoft は 11/16 から残りのルートを削除（Windows・Edge では既存の証明書も既定で信頼されない）。Apple は 11/30 に G1 の証明書すべての信頼を終える（eMudhra の告知による）。チェーンに emSign / eMudhra / InCommon … G2C があれば取り直す。
