セキュリティ朝刊

11月24日（火）の朝刊

今日のひとこと：アンケートサイト「リサーチパネル」や「ECナビ」と同じパスワードを他のサービスでも使っているなら、今日そのパスワードを変えてください。

1アンケートサイトでパスワードが「元に戻せる形」のまま流出のおそれ。学習塾では口座番号も

ポイントがたまるアンケートサイト「リサーチパネル」が不正アクセスを受け、ログイン用のメールアドレスとパスワードなどが漏れたおそれがあると 11/21 に発表しました。

同社は、多くの会員のパスワードを元の文字に戻せる形で保存していたと説明しています。氏名・性別・郵便番号、提携する「ECナビ」の ID も対象です。件数は公表されていません。同じ 11/21 には、学習塾を運営するベストコも、在籍者 最大約5万件と過去の問い合わせ 最大約9.6万件について、保護者と子どもの氏名・住所、引き落とし口座の番号、学習アプリの ID とパスワードが漏れたおそれがあると発表しました（カード情報は含まれないとしています）。

みんながやること
  • リサーチパネル・ECナビ・ベストコの学習アプリと同じパスワードを使っているサービスがあれば、そちらを今日変える
  • リサーチパネルは、届いた案内や公式サイトの手順でパスワードを設定し直す（メールのリンクではなく、ブックマークから）
  • ベストコの利用者は、口座の引き落とし履歴に覚えのないものがないか確かめる

元に戻せる形：本来パスワードは、元に戻せない形（ハッシュ値）に変えて保存します。元に戻せる形だと、盗んだ人にパスワードそのものが分かってしまいます。

2広告から古い iPhone に入り込み、暗号資産やパスワードを盗む攻撃

ネット広告の配信の仕組みを使い、古い iOS の iPhone を攻撃用のページに送り込んで、開いただけで情報を盗むプログラムを入れる攻撃が、セキュリティ会社の調査で見つかりました。

5月から11月中旬まで、47か国以上で 480 を超える広告用のドメインが使われていました。狙われるのは暗号資産のウォレットを元に戻すための言葉（復元フレーズ）、保存したパスワード、メッセージなどです。対象は iOS 13〜18 の古い版で、最新の iOS 向けの攻撃は確認されていません。

みんながやること
  • iPhone・iPad を、その端末で入れられる最新の iOS に更新し、自動アップデートをオンにする
  • 広告から開いたページでログインしない。使いたいサービスは公式アプリやブックマークから開く
  • 暗号資産の復元フレーズを写真やメモに残さない

3メルカリでも流出。AI ツールの裏側の会社が不正アクセスを受けた

メルカリは、社員が業務で使う AI ツール（Notion AI）の処理を請け負う会社が不正アクセスを受け、社員が AI に入力した記録の一部から、利用者 1,522人を含む最大3,796人分の情報が漏れたおそれがあると発表しました。

利用者は、人によって氏名・メールアドレス・住所・電話番号・生年月日や問い合わせの内容などが含まれます。ログインパスワードとクレジットカードの番号は含まれていないとしています。同じ会社への不正アクセスは、ほかの AI サービスにも影響が広がっています。

みんながやること
  • メルカリを名乗るメール・SMS・電話で、パスワードや確認コードを聞かれても答えない（メルカリは聞かないとしています）
  • お知らせはメルカリのアプリの中で確かめる
  • 仕事で AI を使うときは、お客さんの個人情報をそのまま貼らない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Ruby「Ruby2Shell」CVE-2026-132825：実証コードの公開予定はあす 11/25 以降

  • 修正版は 4.0.10 / 3.4.13 / 3.3.14（11/18）。標準の Rails（api_only 以外）とクラシック形式の Sinatra は Rack::MethodOverride 経由で認証の前に届くとされる。3.2 以前は修正なし。
  • gem の更新では直らない。動いているプロセスの Ruby の版を確かめ、上げてアプリサーバーを再起動する。WAF の仮の規則（CrowdSec など）は修正の代わりにならない。
  • 攻撃の報告・CISA KEV への追加は今朝の時点で見つかっていない。MITRE の採点は CVSS 7.4（攻撃元区分はローカル）で、「クリティカル」とするブログとは食い違う。

2. ConnectWise ScreenConnect CVE-2026-84869（CVSS 9.9）：悪用あり

  • 悪意あるゲスト側から技術者の PC にファイルを送り、技術者のクライアントに確認なしで実行させられる。10/20〜11/16 に 42台のサーバーへ少なくとも 68.8万件の「ファイル実行」の要求が観測され、偽の Windows Update から攻撃者の中継先につながる別の ScreenConnect を入れる例も確認された（Huntress）。
  • やること：ホスト側クライアントを 26.6.5 以上に。すぐ無理ならロールとセッショングループから TransferFiles の権限を外す。痕跡を調べ、該当する端末を切り離し、そこから使えた認証情報を交換する。

3. ASP.NET WebForms の Idunno.AntiCsrf CVE-2026-131914（CVSS 9.3）：悪用あり、修正なし

  • 0.9.1.0 / 0.9.1 Beta の AntiCsrfModule が、CSRF のフォーム値を MAC の検証なしに ObjectStateFormatter で逆シリアル化する。認証なし・POST 1回で w3wp.exe の中でコードが動く。Mandiant が悪用を確認。プロジェクトは 2008年から止まっている。
  • やること：Web.config と bin/ で Idunno.AntiCsrf / AntiCsrfModule を探し、System.Web.Helpers.AntiForgery・ViewStateUserKey＋MAC 付き ViewState・ASP.NET Core の IAntiforgery へ移す。.aspx への不審な POST（302 / 500）をログで確かめ、跡があれば machineKey と DB の認証情報を交換する。

4. React CVE-2026-130165（CVSS 8.2）：サーバー関数への細工した要求で DoS

  • 対象：react・react-server-dom-webpack / -turbopack / -parcel の 19.0〜19.3 系の古い版。認証なしでメモリ不足・CPU の張り付きを起こせる。回避策の記載はない。
  • 修正：19.0.9 / 19.1.10 / 19.2.9 / 19.3.1（npm に 10/14 に公開済み、CVE の公開は 11/23）。GHSA-h3gv-c5rc-p453。Next.js などフレームワークが同梱する React の版も確かめる。
  • 悪用・公開の実証コードの報告はない。

5. GL.iNet：クラウド管理 GoodCloud 経由でルーター・KVM にマルウェア（CVE なし）

  • GoodCloud のクライアントがクラウドからの値を確認せずに root で実行するとされる（研究者の分析）。GL-AXT1800 で root のリバースシェル、GL-RM1 で LAN の走査を確認。GL.iNet はクラウド側を修正したが、感染済みの機器は残る。
  • 修正版：GL-MT3000 / GL-MT6000 4.11.1、GL-AXT1800 4.8.4、GL-MT2500 / GL-X2000 4.7.14、RM1 系 1.10.3、RMQ1 1.8.7。
  • やること：再起動・更新の前に ps | grep tmp（crond -i /tmp/.log）を確認（見つからなくても安全とは限らない）。感染していれば設定を引き継がずに入れ直し、VPN の鍵・Wi-Fi と管理のパスワード・SSH 鍵を交換。すぐ更新できなければ GoodCloud を切る。

6. 情報漏洩（開発・運用の目線で）

  • リサーチパネル：サイト内検索の欠陥を突かれ、ログイン用のメールアドレス・パスワードが漏えいのおそれ。パスワードの多くを元に戻せる形、一部は変換しない形で保存していた。パスワードは必ず bcrypt / scrypt / Argon2 などで保存し、古い形式の残りがないか点検する。
  • メルカリ：Notion AI の処理を請け負う Fireworks AI への不正アクセスで、社員が AI に入れた記録から最大3,796名分と社内システムの一部の認証情報が流出（認証情報は無効化・再発行済み）。AI ツールに貼った認証情報は、その先の事業者まで届く前提で扱う。
  • ベストコ：口座番号・教育アプリの ID とパスワードを含む最大14.6万件。
