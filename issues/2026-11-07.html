セキュリティ朝刊

11月7日（土）の朝刊

今日のひとこと：無印良品の件で、カード番号を含む情報も流出していたと分かりました。「MUJI Card」を持っていた人は、カードの利用明細を確かめてください。

1無印良品：MUJI Cardの番号など約109万件も流出していた

先日お伝えした無印良品のアプリの件で、11月4日の第二報で、クレジットカード「MUJI Card」の情報も含まれると公表されました。

2021年7月までに入会したMUJI Card会員の約109万件で、カード番号（全桁）・会員ID・生年月日が対象です。いま有効なカードは約34.5万件とのことです。アプリやネットストアにカード情報を登録した約120人は、番号の先頭6桁と下2桁、名義が対象です。ほかに、アプリ・ネットストアの利用者は最大約2,726万件（メール・生年月日・性別・会員IDなど）で、うち約52万件は氏名・住所・電話番号も含まれます。対象の人には、メールか郵送で個別に連絡があります。

みんながやること
  • MUJI Cardを持っていた人は、カードの利用明細に身に覚えのない請求がないか確かめる。不安ならカード会社に相談する
  • 「カードを確認してください」などの名目のメール・SMSのリンクは開かず、公式アプリや公式サイトから確かめる

2@cosme約300万人、クラブツーリズム約432万件の会員情報が流出のおそれ

化粧品口コミサイトの@cosmeと、旅行会社のクラブツーリズムが、会員情報の流出を公表しました。

@cosme（アイスタイル）は、約300万人分の氏名・住所・電話番号・メールアドレス・生年月日・肌質などが流出したと11月2日に公表しました（記事にパスワードやカード情報の記載はありません）。クラブツーリズムは、インターネット会員約432万件の氏名・住所・電話番号・メールアドレス・生年月日・緊急連絡先などが流出した可能性があると10月31日に公表しました。同社はホームページを停止しています。どちらも、対象の人へ会社から順に連絡が来ます。

みんながやること
  • 使っていた人は、会社からの連絡を待ち、公式サイトのお知らせを自分で開いて確かめる
  • 住所や電話番号が知られている前提で、旅行の「キャンセル料」や「返金」を名乗る電話・メール・SMSを疑う

3サントリー約10万人分、日本郵便のメール配信先でも不正アクセス

会社が外部のクラウドサービスや委託先に預けていたデータが狙われる事例が続いています。

サントリーグループは、外部のクラウドサービスへの不正アクセスで、従業員・取引先従業員のほか、マル・デ・シャインの登録顧客（7,323人）や新卒採用の応募者（7,173人）など、合計およそ10万6千人分の氏名・メールアドレス・電話番号などが含まれるファイルが取られたと11月2日に公表しました。日本郵便は、メールマガジンの配信を委託している会社が不正アクセスを受け、国際郵便マイページの会員のうち案内メールを希望していた人のメールアドレスが漏れた可能性があると10月29日に公表しました。

みんながやること
  • メールアドレスが知られた可能性があるので、「荷物が届いています」「再配達」などの郵便・宅配を名乗るメールやSMSのリンクを開かない
  • 本物か迷ったら、メールのリンクではなく公式アプリや公式サイトから確かめる

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. 続報：WordPress の wp2shell、Brotli CVE-2026-111497（CISA の期限 11/10）、PHP2Shell

  • Brotli：CISA の連邦機関向け期限は11/10。Node.js は 22.23.4 / 24.22.1 / 26.12.1 以上、.NET 8〜11 は10/25の緊急更新、Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。更新後はプロセスの再起動とイメージの再ビルドが必要。
  • WordPress：6.9.5 / 7.0.2 以上（6.8 系は 6.8.6 以上）。CVE-2026-63030（CVSS 9.8）／ CVE-2026-60137。攻撃コードが公開されている。管理者ユーザーと入っているプラグインに身に覚えのないものがないか確認。
  • PHP2Shell（CVE-2026-109618 / 109619、悪用あり）：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上。CVE-2026-115560 の回避策は session.upload_progress.enabled=0。

2. Ivanti Connect Secure：2件の追加のゼロデイが連鎖して悪用（報道ベース）

  • 報道（BleepingComputer 11/2、SecurityWeek）によると、CVE-2026-111357 と CVE-2026-118527 が、10月に修正された CVE-2026-104935 と連鎖して、少なくとも10/1から悪用されていた。Ivanti が修正を出し、CISA が悪用済みリスト（KEV）に追加したとされる。
  • やること：Connect Secure を運用していれば、Ivanti の勧告で修正版を確認して適用し、整合性チェックツール（ICT）の結果と、管理者・認証まわりのログを見直す。（検索結果の要約を読んだだけで、Ivanti の勧告・CISA の原文は未読。CVE と版は原文で要確認）

3. 委託先・外部クラウド経由の流出が続く：サントリー、日本郵便、MUJI（レガシーデータ）

  • サントリー：外部クラウドサービスへの不正アクセスで、個人情報を含むファイルがダウンロードされた（10/28検知、約10.6万件）。日本郵便：メール配信の委託先サーバーへの不正アクセス（メールアドレスのみ）。
  • MUJI：2021年7月以前に提携カード会員の番号・ID・生年月日を取得し、システムに残っていたものが流出対象に含まれた。クラブツーリズム（約432万件）は侵入経路を調査中。
  • やること：不要になった個人情報・カード関連データの棚卸しと削除、外部クラウドの共有リンク・API キー・多要素認証・IP 制限の確認、委託先への提供項目の最小化。（ScanNetSecurity の記事を読んだ。会社の原文は未読）

4. 続報：eMudhra

  • Chrome の emSign ECC Root CA – G3 削除（10/27 PT 予定）の実施結果と Apple の追加更新は、今朝も一次情報で確認できなかった。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上に。
