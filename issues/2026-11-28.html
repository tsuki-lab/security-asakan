セキュリティ朝刊

11月28日（土）の朝刊

今日のひとこと：ソフトは検索結果の広告やリンクからではなく、公式サイトから入れてください。それでも「おかしい」と感じたらウイルス対策ソフトで全体を調べましょう。

1公式サイトで配られていた Windows のソフトにウイルス

Windows のファイル管理ソフト「Q-Dir」とデスクトップのアイコン配置を保存する「DesktopOK」で、開発元の公式サイトから配られていたファイルに、パソコンを遠隔操作するウイルスが仕込まれていました。

新しく入れた場合だけでなく、入っているソフトの更新でも配られていました。ソフトは普通に動くので気づきにくく、裏で Microsoft Edge を装った自動実行の設定を作ります。別の件では、Microsoft Store に並んでいたアプリ「Setup Assistant」が、検索結果から誘導された偽の「切り取りツール」のページ経由で入れられ、パソコンを乗っ取るウイルスを入れていました（今はストアから消えています）。

みんながやること
  • Q-Dir・DesktopOK を最近入れた・更新した人は、ウイルス対策ソフトでパソコン全体を調べる（ソフトを入れ直すだけでは消えない）
  • ソフトは検索結果の広告や知らないサイトからではなく、開発元の公式サイトや公式ストアから入れる

2化粧品のヴェレダの通販でカード情報、東京海上ダイレクトでは事故の情報も流出

化粧品「ヴェレダ」の公式通販サイトで、約20万件の個人情報と約4.6万人分のクレジットカード情報（裏面の3桁の番号を含む）が流出したおそれがあると報じられました。

自動車保険の東京海上ダイレクトでは、契約者向けのマイページとアプリに不正なアクセスがあり、93人分の名前・住所・車の登録番号・保険の契約内容・事故の情報・カード番号の下4桁などが流出しました。文部科学省の調達のシステムからも、取引先の会社名と代表者の名前など最大約16万件が流出したおそれがあります。

みんながやること
  • ヴェレダの通販で買い物をしたことがある人は、カードの利用明細を確かめ、覚えのない請求があればすぐカード会社へ
  • 契約内容や事故のことを知っている相手からの連絡でも、本物とは限らない。保険会社の公式アプリや証券に書かれた窓口から確かめる

セキュリティコード：カードの裏面などにある3〜4桁の番号。番号・期限と一緒に盗まれると、ネットで勝手に使われやすい。

3KARTE 経由の流出がみずほ銀行・ニューバランスなどにも

多くの企業のサイトに組み込まれているサービス「KARTE」への不正アクセスで、みずほ銀行・ニューバランスジャパン・化粧品のアテニアなども顧客の情報が流出したと公表しました（インシデントの一覧サイトによる）。

みずほ銀行は社内で使う顧客の管理番号だけで、名前・暗証番号・ログイン ID は含まれないとしています。どの会社もパスワードの流出は挙げていません。ただ、流出の連絡や「返金」を装った偽のメール・SMS が届きやすい時期です。

みんながやること
  • 「情報流出のお詫び」「返金の手続き」などのメール・SMS のリンクは開かず、公式アプリやブックマークから確かめる
  • 暗証番号やパスワードを電話やメールで聞かれても答えない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM・電話には従わず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Cacti 1.2.31：ゲストのアカウント経由で認証なしの RCE「4HTTP2SHELL」（root まで「4HTTP2ROOT」）— 修正なし

  • ゲストのアカウントを有効にしている Cacti Core 1.2.31（記事の時点の最新）で、HTTP 要求4回でコードを実行される。CVE 未採番・修正版なし、実証コードは公開済み。実際の攻撃の報告は記事に無い。
  • 当座の策：ゲストを無効にする（0.8.7 以降は既定で無効）、Web 画面への到達を絞る、ポーラーの設定に覚えのないコマンドが無いか確認。修正が出たらすぐ当てる。

2. Q-Dir / DesktopOK の公式配布物の改ざん（サプライチェーン）

  • Q-Dir 12.83.0.0 / 12.84.0.0 / 12.85.0.0、DesktopOK 12.82.0.0 / 12.85.0.0。直接のダウンロードとアプリ内の更新の両方。改ざんの経路は不明。
  • 本物のアプリを動かしつつ mail.c1a2[.]top から 7zr.exe と dsv2_py39_agent.7z を取得、Edge を装う予定タスクで py_client_dsv2.py（Python 製 RAT）を常駐。C2 は 8.210.69[.]51:9876。
  • 社内の Windows 端末に配っているなら SHA-256 を正規のものと比べ、予定タスク・C2 への通信を確認。

3. BusyBox 1.38.0 以前：tftpd のパストラバーサル CVE-2026-136411（CVSS 9.8）

  • tftpd を対象ディレクトリの指定なしで起動すると、認証なしで任意のファイルを読み書きできる。11/6 にソースで修正、11/24 時点で修正を含むリリースはない。悪用の記述はない。
  • 組み込み機器・Alpine 系のイメージで tftpd を動かしていなければ影響なし。使うならディレクトリを指定し、外から届かないように。

4. SolarWinds Serv-U 2026.4（11/24）：18件、Critical 9件

  • Linux で root への昇格（CVE-2026-123172・CVE-2026-123168）、型の取り違えでドメイン管理者がシステム管理者に（CVE-2026-82320 / CVE-2026-82321）、ファイルの読み書きからコード実行（CVE-2026-82315 / CVE-2026-82316）ほか。対象の版・悪用の有無は記事に無い。

5. Microsoft Store のアプリ「Setup Assistant」から Vinci RAT

  • 偽の Snipping Tool サイト（snipp.codes-team[.]com）から Microsoft 署名のインストーラーで Store のアプリ（ETPS Ltd、Electron 製、6/1 公開）を入れさせ、C2（setup-assistant[.]com・monkeysholder[.]info）の指示で PowerShell を実行。AMSI を無効化し 10分ごとのタスクを作る。Store の審査や署名があっても安全とは限らない例。
