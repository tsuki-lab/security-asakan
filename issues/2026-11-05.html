セキュリティ朝刊

11月5日（木）の朝刊

今日のひとこと：無印良品と松屋のアプリの会員情報が流出しました。使っていた人は、公式アプリ・サイトのお知らせを自分で開いて確かめ、松屋のパスワードは変えてください。

1無印良品「MUJIアプリ」の情報 最大約2,726万件が流出のおそれ

良品計画が、公式アプリへの外部からの不正なアクセスを検知したと公表しました。

公表は10月30日です。流出したおそれがあるのは、メールアドレス・生年月日・性別で、退会済みの人の情報も含まれます。会社は該当箇所のアクセスを遮断して直したとしており、対象の人には順次連絡するとしています。侵入された経路は、記事には書かれていません。

みんながやること
  • アプリを使っていた（退会した人も）なら、会社からの連絡を待ち、公式アプリ・公式サイトのお知らせを自分で確かめる
  • 「確認のお願い」を名乗るメール・SMS のリンクは開かない。メールアドレスと生年月日は知られている前提で警戒する

2松屋のアプリなどで約238万件が流出のおそれ

松屋フーズが、公式アプリの管理システムへの不正アクセスを公表しました。

10月28日に第三者が入り込み、10月30日に公表されました。公式アプリの登録者（約2,000件、最大3,000件の可能性）は、氏名・電話番号・生年月日・メール・暗号化されたパスワードなどが対象です。「松弁ネット」やモバイルオーダー、デリバリーの利用者（約238万件）は、氏名・住所・電話番号などが対象です。公式アプリは停止中で、注文やポイントが使えません。

みんながやること
  • 使っていた人は、会社からの連絡を確かめる。アプリのパスワードは変え、同じパスワードを使い回した他のサービスも変える
  • 住所や電話番号が知られている前提で、「配達」「当選」を名乗る不審な電話・SMS に注意する

3ノジマの約700万件、スマートニュースの件は続報待ち

先日お伝えしたノジマ（約700万件）とスマートニュースの件で、新しい発表は今朝は見つかりませんでした。

ノジマの2つのサイトは一時休止中で、スマートニュースもポイント交換などを止めています。まだ対応していない人は、パスワードの変更とポイント残高の確認をしておいてください。

みんながやること
  • 会員だった人は、パスワードを変え、使い回しのある他のサービスも変える
  • 「再登録」「再認証」を名乗る連絡のリンクは開かず、公式の入り口から確かめる

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. WordPress 6・7 系の wp2shell：CVE-2026-63030（CVSS 9.8）／ CVE-2026-60137、攻撃コード公開

  • REST API のバッチ処理のルート取り違え（CVE-2026-63030）と、WP_Query の author__not_in の SQL インジェクション（CVE-2026-60137）。設定を変えていない環境でも、ログインなしで遠隔コード実行につながりうる。流れは、SQL インジェクションで管理者を作り、悪性プラグインを入れて実行、とされる。
  • 影響：6.9.0〜6.9.4、7.0.0〜7.0.1（SQL インジェクションのみ 6.8.0〜6.8.5 も）。修正版：6.9.5 / 7.0.2 以上、6.8 系は 6.8.6 以上。攻撃コードが GitHub で公開されている。
  • やること：自動更新を確認して更新。管理者ユーザーと入っているプラグインに身に覚えのないものがないか確認し、あれば侵害を疑ってパスワード・鍵を取り替える。記事内で CVE 番号の表記が揺れているため、WordPress の公式勧告でも確認する。（ScanNetSecurity の記事を読んだ）

2. 会員向けアプリの管理システムへの侵入：松屋フーズ（約238万件）、良品計画（最大約2,726万件）

  • 松屋は「公式アプリの管理システム」への第三者の不正アクセス（10/28）。パスワードは暗号化されたものが対象と説明されている（方式は記事になし）。MUJI アプリは外部からの不正なアクセスとだけ書かれ、経路は未公表。
  • 自社のアプリ・サービスでは、管理画面の IP 制限と多要素認証、会員 DB へのアクセスの監査ログ、パスワードの一方向ハッシュ（bcrypt / Argon2 など）を確認する。（ScanNetSecurity の記事を読んだ。会社の原文は未読）

3. 続報：Brotli CVE-2026-111497（CISA の期限 11/10）、PHP2Shell、eMudhra

  • Brotli：Node.js は 22.23.4 / 24.22.1 / 26.12.1 以上、.NET 8〜11 は10/25の緊急更新、Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。更新後はプロセスの再起動とイメージの再ビルド。
  • PHP2Shell（CVE-2026-109618 / 109619、悪用あり）：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上。CVE-2026-115560 の回避策は session.upload_progress.enabled=0。
  • eMudhra：Chrome の emSign ECC Root CA – G3 削除（10/27 PT の予定）の実施結果や Apple の更新は、今朝も一次情報では確認できていない。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上（できれば 1.0.11）に。
出典
  • 「MUJIアプリ」で最大 約2,726万件の顧客情報が流出した可能性（ScanNetSecurity）
  • 松屋公式アプリに不正アクセス 会員情報等が漏えい（ScanNetSecurity）
  • WordPress 6系および 7系における遠隔からの任意のコード実行が可能となる複数の脆弱性（ScanNetSecurity）
