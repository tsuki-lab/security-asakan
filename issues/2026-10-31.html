セキュリティ朝刊

10月31日（土）の朝刊

今日のひとこと：会員登録しているサービスから「情報が漏れた」と連絡が来たら、メールのリンクは開かず、公式サイトのお知らせを自分で開いて確かめてください。

1阪急・阪神百貨店の予約サイトから、約126万人分の会員情報が漏えい

百貨店の予約サイトなどで使う「H2O ID」の会員のほぼ全員分の、名前・住所・電話番号などが外に出た可能性があります。

運営するエイチ・ツー・オー リテイリングが10月19日に発表しました。10月16日に不正なアクセスが見つかり、サイトは停止されています。名前・性別・メールアドレス・住所・電話番号・生年月日などが対象です。ネット通販サイトなど別のサービスでも、注文履歴やカード情報の一部（カードの種類・下4桁・名義・有効期限）が保管されており、漏れたかどうかは調査中です。会社から会員へ順にメールで連絡するとのことです。

みんながやること
  • 使ったことがある人は、会社からの連絡を待ち、公式サイトのお知らせを自分で開いて確かめる
  • 「会員情報の確認」「ログインのお願い」を名乗るメール・SMS のリンクは開かない
  • カードの利用明細に身に覚えのない請求がないか、ときどき見る

2ニフティの回線申込システムと、チケット購入サービス「GETTIIS」でも会員情報が流出

インターネット回線を申し込んだ人や、チケットを買った人の名前・住所・電話番号などが、不正なアクセスで外に出ました。

ニフティは10月19日に発表しました。2019年以降に光回線などを申し込んだ最大約54万人が対象で、氏名・住所・電話番号・生年月日・メールアドレスなどが含まれる可能性があります。パスワードやカード情報は、確認した範囲では含まれていないとされています。「GETTIIS」を運営するリンクステーションでも、10月18日に不正なアクセスがあり、約32万人分の会員情報（名前・電話番号・メールアドレス、暗号化されたパスワード）が流出しました。うち約3万人はカードの前後4桁などの情報も含まれていました。

みんながやること
  • 使っている人は、会社からのメールを確認する（本物かどうかは、公式サイトのお知らせで確かめる）
  • GETTIIS を使っていた人は、パスワードを変える。同じパスワードを使い回している他のサービスも変える
  • 「回線の契約確認」「チケットの確認」を名乗るメール・SMS のリンクは開かない

3GMO「お名前.com デスクトップクラウド」：情報が公開された人に、最大300万円の見舞金

一部の利用者の環境に不正なプログラムが入れられ、盗まれた情報が公開された問題で、会社が見舞金を発表しました。

公開された情報の種類（連絡先などの基本情報、ID・パスワードなどの認証情報、特に配慮が必要な情報）ごとに、1万円・1.5万円・2.5万円が払われ、上限は1回の公開につき300万円です。会社は、犯人の要求には応じないこと、流出したデータを再投稿・共有しないこと、この件に便乗した詐欺メール・電話に注意することを呼びかけています。24時間受け付けの相談窓口もあります。

みんながやること
  • 流出したとされるデータを、SNS などで拡散・共有しない
  • 「見舞金の手続き」を名乗るメール・SMS・電話は、公式サイトに載った窓口かどうかを確かめる
  • 対象かもしれない人は、会社の案内にある窓口へ相談する

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. 「入口」と「社内の管理画面」を突かれた事案が続く

  • GETTIIS（リンクステーション、10/18）：イベント主催者向けの登録サービス「Gettii-Lite」の脆弱性を突かれてサーバーに侵入され、会員データを取得された。会員 ID 317,971、ハッシュ化パスワード 311,451、カード関連（先頭4桁・末尾4桁・名義・有効期限。暗号化）29,515 など。サーバーの切り替えと脆弱性の修正は済み、原因と範囲は調査中。
  • ニフティ（10/19）：職員が顧客情報を登録する社内の回線申込・受付管理システムに外部から不正アクセス。最大 542,513 件（会員 ID・氏名・性別・生年月日・住所・電話・メール）。顧客向けの申込フォームは別系統。侵入経路は記事に記載なし。
  • H2O リテイリング（10/16〜19）：予約サイト経由で顧客管理システムへ不正アクセス。約126万人の H2O ID 会員。ネット通販（HANKYU HANSHIN E-STORES）と Remo Order も停止。原因は調査中。
  • Gunosy（10/21、10/26 発表）：業務用アカウントの ID・パスワードが不正に入手され、クラウド環境・業務ツールにログイン。取引先25人と役員・従業員107人の情報が対象。共有アカウントを廃止し、多要素認証を必須にしたとのこと。
  • 示唆：社内向けの管理系システムも外部から到達できるなら、公開サイトと同じ強さで守る（多要素認証、IP 制限、共有アカウントの廃止、権限の棚卸し）。委託先・周辺サービス（主催者向けの登録ツールなど）の脆弱性が本体の DB に届かないよう、権限と接続を分ける。

2. So-net・plala：内訳（10/27 発表、前号までの続き）

  • So-net 会員 2,141,986 件（現会員 1,869,771、退会者 272,215）、plala（S コース）443,495 件。氏名・電話・メール・ユーザー ID・生年月日・性別・接続 ID。
  • メールサービスのメールアドレスとパスワード 54,401 件（G 24,655、A-Box 17,672、Sonet VAIO Mail 7,005、PostPet 5,069）、銀行口座情報 16 件、パスワード再設定の案内の情報 7 件。侵入は 10/19、確認は 10/23。原因は調査中。

3. GMO「お名前.com デスクトップクラウド」（第12報）

  • 顧客サーバーに不正なプログラムが設置され、取引口座のログイン情報などが盗まれ、一部が公開された。見舞金は区分ごとに 1万円・1.5万円・2.5万円、上限は 1 回の公開につき 300 万円。犯人の摘発につながる情報への懸賞金（最大 100 万ドル）も設定。
  • 示唆：同様の VPS・デスクトップ型の環境を使っている場合は、サーバー内に保存した認証情報（ブラウザの保存パスワード、API キー）を最小限にし、見つかったら再発行する。

4. PHP2Shell／Brotli／eMudhra／LiteLLM（続報なし）

  • PHP2Shell（CVE-2026-109618 / 109619）：修正版は 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35。8.1 以前は公式の修正なし。CVE-2026-115560 の回避策は session.upload_progress.enabled=0。
  • Brotli の C 実装（CVE-2026-111497）：1.2.1 / 1.1.1 / 1.0.10。Node.js は 22.23.4 / 24.22.1 / 26.12.1。
  • eMudhra：Chrome は emSign ECC Root CA – G3 を 10/27 PT に外す予定だった。今朝の検索では実施後の追加の発表を確認できなかった。Apple の /etc/ssl/cert.pem（curl・git など）は将来の macOS 更新まで受け入れうるとされ、手順は Apple のサポート記事 149555。発行元に emSign / eMudhra があれば別の CA で取り直す。
  • LiteLLM 1.107.0（マルウェア版。安全な版は 1.106.2）、npm / PyPI の新しい侵害：今朝の検索では新しい動きを確認できなかった（確認できなかっただけで、無いとは限らない）。
