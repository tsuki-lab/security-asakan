セキュリティ朝刊

10月24日（土）の朝刊

今日のひとこと：スマホ・PC・ブラウザを「最新に更新して再起動」しておきましょう。

1本物そっくりの偽サイトを作れる「鍵」が漏れていた

偽サイトを本物に見せかけられる「鍵」が漏れました。ブラウザ側はもう対策済みです。

Web サイトの「身元保証書」（証明書）を出しているインドの会社 eMudhra で、保証書を作るための大事な鍵が、誰でも割り出せる状態だったと分かりました（10月17日に報告）。この鍵があれば、銀行や通販サイトにそっくりな偽サイトを「本物」と見せかけることができてしまいます。

Chrome・Firefox・Safari（Apple）・Windows（Microsoft）は、すでにこの鍵で作られた保証書を受け付けないようにしています。今のところ悪用されたという報告はありません。この会社は、Web サイト向けの保証書の事業から撤退すると発表しました。

みんながやること
  • スマホ・PC・ブラウザを最新に更新して、一度再起動する
  • 「この接続は安全ではありません」「保護されていない通信」と出たら、先へ進まずにページを閉じる

ことば：証明書＝そのサイトが本物であることを保証する電子の身分証。ブラウザの鍵マークの中身。

2PHP に深刻な欠陥。各地でサービスが一時停止

多くのサイトを動かす PHP に、乗っ取りにつながる欠陥が見つかりました。

世界中の多くの Web サイトで使われている PHP（サイトを動かすためのプログラムの言語）に、外からサーバーを乗っ取れてしまう深刻な欠陥が見つかり、10月21日に修正版が出ました。攻撃しようとする動きも確認されています。

対応のため、ソフトバンクの緊急速報メールが一時止まるなど、国内でもサービスを止めて点検する会社が相次ぎました。サイトの更新が遅れているところでは、まだ危ない状態が続いています。

みんながやること
  • 使っているサービスの「メンテナンス」「お知らせ」が出ていたら目を通す
  • 自分でブログやお店のサイトを持っている人は、サーバー会社のお知らせを確認し、案内どおりに更新する

3個人情報の漏えいの発表が続いています

大手の個人情報漏えいが続き、それに便乗した詐欺メールが増えています。

10月23日だけでも、佐川急便（荷物の問い合わせサービス。最大約5,323万件の可能性）、トレジャー・ファクトリー、タイムズカー（本人確認書類の画像）、グッドスマイルカンパニー公式ショップなどが、不正アクセスによる漏えいやその可能性を発表しました。

こうした発表のあとは、漏れた情報を使って本物の会社を装うメールや SMS が増えます。名前や注文内容が合っていても、本物とは限りません。

みんながやること
  • 「返金します」「配送を確認してください」「本人確認が必要です」というメール・SMS のリンクは開かない
  • 確かめたいときは、公式アプリやブックマークから自分で開く
  • 同じパスワードを使い回しているなら、この機会に変える

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。

1. eMudhra の鍵漏えい：ブラウザ以外の信頼ストアを更新

  • 修正版：Node.js 22.23.4 / 24.22.1 / 26.12.1（10/21。Node 自体の脆弱性10件も修正）、Python の certifi 2026.10.18 以上・pip 26.2.2 以上・uv 0.13.4 以上（仮想環境ごとに更新）、Go 1.27.3 / 1.26.10（バイナリの再ビルドが必要。1.25 以前は修正なし）、Java は 10/21 の緊急更新（Temurin など配布元ごとの cacerts に注意）。
  • Docker イメージは作った時点の証明書を持つので、--pull --no-cache で作り直す。
  • macOS 標準の curl・git・python3 が読む /etc/ssl/cert.pem は、報道時点で未更新。
  • Chrome は 10/27（米国太平洋時間）に「emSign ECC Root CA – G3」を信頼リストから外す予定。自分のサイトの証明書がこのルートに連なっていないか確認する。

2. PHP2Shell（CVE-2026-109618 / 109619、CVSS 9.2）

  • 修正版：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35。8.1 以前は公式の修正版がなく、7.4〜8.1 向けには最小限のソースパッチのみ。悪用の試行が観測されている。
  • 10/23 には別の未修正の欠陥 CVE-2026-115560 も公表。影響は限られた設定のみで、session.upload_progress.enabled=0 で防げる。

3. サプライチェーン攻撃

  • PyPI：litellm==1.107.0（10/21。PyPI と Docker の v1.107.0・latest など）に、認証情報を盗む仕掛けとリモートからコードを動かす仕掛けが入っていた。Python を起動するだけで動く。1.106.2 以前は安全。入れた環境は作り直し、そこから届く鍵・トークンをすべて交換する。
  • npm：MALFEX（imgdecode など）や、Shai-Hulud 系のワーム（10/5・10/8 に @subql/common、tensorlake が侵害）が続いている。ロックファイルの作り直しや依存の一括更新は、侵害版が取り下げられたか確認してから。

4. そのほかの修正

  • Ruby 4.0.9 / 3.4.12 / 3.3.13（10/23）：正規表現エンジンの欠陥を修正。外部からの入力で正規表現を組み立てるアプリは更新する。
  • 米 CISA の悪用済みリストに追加：Plex Media Server（Plex2Shell）、SiteGuard Server Edition、Siemens Software Center、Ivanti Connect Secure（ゼロデイ）など。
