セキュリティ朝刊

11月21日（土）の朝刊

今日のひとこと：Web ページに「このコマンドを貼り付けて実行してください」と言われたら、どんなに本物らしく見えても閉じてください。

1家電量販店のリフォームや通販の注文情報が流出。ヤマダデンキ、多くのネットショップが使うサービスなど

ヤマダデンキは、リフォームの管理システムに不正アクセスがあり、最大350万件のお客さんの情報が流出した可能性があると発表しました。

対象は氏名・住所・電話番号と、リフォームの履歴・見積もりの内容です。また、多くのネットショップが注文の管理に使っているサービス「GoQSystem」からは、1,694の店舗の注文情報（約437万人分の氏名・住所・電話番号・メールアドレス・注文内容）が持ち出されました。楽天市場や Yahoo!ショッピングの店も含まれ、バリューブックスや銀座ウエストなど約70の店が公表しています。カー用品のソフト99 の公式通販（最大136,968人）では、カード番号の下4桁・名義・有効期限も対象です。スーパーの買い物アプリ「Scan&Go ignica」でも、氏名とメールアドレス 64,003件が流出した可能性があります。どれも、パスワードが流出したという発表はありません。

みんながやること
  • 心当たりのある人は、各社・各店の公式サイトのお知らせを確かめる（メールのリンクからではなく）
  • 買った物や工事の内容を知った上での「お詫び」「返金」「再配達」「点検のご案内」は詐欺を疑い、リンクは開かない・電話は一度切って公式の番号にかけ直す
  • ソフト99 の通販を使った人は、カードの利用明細を確かめる

受注管理サービス：ネットショップが、いくつもの出店先の注文をまとめて処理するために使う裏方のサービス。買った店とは別の会社が、注文の情報を預かっていることがあります。

2「確認のため、このコマンドを実行してください」は詐欺。偽のダウンロードページにも注意

本物そっくりの「確認」や「修正」の画面を出し、利用者自身にコマンドを貼り付けて実行させる手口が広がっています。

検索結果の「広告」の枠から、人気のアプリ（AI アプリの Claude など）の偽のダウンロードページへ誘導し、Mac の「ターミナル」にコマンドを貼らせて、パスワードなどを盗むソフトを入れる例が報告されました。Windows でも、偽の「私はロボットではありません」の画面や偽の Amazon のログイン画面から、画面・マイク・カメラをのぞける遠隔操作ソフトを入れられる例があります。自分で実行してしまうので、ウイルス対策ソフトでも止まりにくいのが厄介なところです。

みんながやること
  • Web ページや電話の相手に「これを貼り付けて実行して」と言われたら、やめて閉じる。本物の確認画面がそれを求めることはない
  • アプリは、検索の「広告」からではなく、公式サイトか公式のアプリストアから入れる
  • 実行してしまったら、その PC をネットから切り、別の端末から大事なサービスのパスワードを変える

3スマホ：「プレミアム版」を名乗る偽アプリに注意。WhatsApp は更新を

Android のスマホで、「大人向けの TikTok プレミアム版」などを名乗る偽アプリから入り込む、新しい不正アプリが報告されました。

SNS の広告や偽サイトから、公式ストア以外のアプリを入れさせます。入ると、本物そっくりの画面を上に重ねて裏の操作を隠しながら、ロック解除の暗証番号や、SMS で届く確認コードを盗みます。また、メッセージアプリの WhatsApp は 3件の欠陥を直しました。うち1件は、詐欺メッセージで使われた可能性があるとされています。

みんながやること
  • アプリは Google Play・App Store から入れる。「提供元不明のアプリを許可」を求められたら断る
  • 設定の「ユーザー補助」に、覚えのないアプリが入っていないか見る
  • WhatsApp を使っている人は、ストアで最新に更新する

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Ruby：CVE-2026-132825「Ruby2Shell」— 標準の Rails・Sinatra に認証の前で届く

  • 11/18 の修正版（4.0.10 / 3.4.13 / 3.3.14）が直した 7件のうちの1件に CVE が付いた。対象は 4.0.0〜4.0.9、3.4.0〜3.4.12、3.3.13 以前（10/23 の版も対象）。3.2 以前は修正なし。JRuby・TruffleRuby は対象外とされる。
  • 中身：14 種類の単一バイトの文字コードでの大文字小文字変換（upcase・swapcase・downcase(:fold)・casecmp?）で、ß が「SS」に伸びるときに 1バイトだけ外に書く。
  • 届き方（発見者の説明）：_method の部分に対象の文字コードを名乗らせた multipart のリクエストを、Rack::MethodOverride がルーティング・CSRF の確認・認証より前に処理する。標準の Rails（api_only 以外）とクラシック形式の Sinatra は既定で届く。Rack 3.2.2 は multipart の大きさの制限でこの経路を塞ぐとされる（根本の対策ではない）。
  • 評価は分かれている（Ruby は Critical、Red Hat は暫定 9.8、MITRE は 7.4）。Ruby は「一部の条件でコード実行に使える実証コードを把握している」と説明。発見者は 11/25 以降に実証コードを公開する予定。攻撃の報告はなく、CISA KEV にも入っていない（11/20 時点）。
  • 配布の状況（11/20 時点）：Ubuntu は USN-9176-1 で修正済み。Debian・Red Hat・SUSE・Amazon Linux 2023 はまだ。Docker 公式の Ruby イメージと Heroku は更新済み。GitLab 19.6.1 / 19.5.8 / 19.4.10、Mastodon 4.7.6 ほか、Chatwoot 4.20.1 が Ruby を更新した版を出した。
  • やること：動いているプロセスの Ruby の版を確かめ、修正版へ上げてアプリサーバーを再起動（gem の更新では直らない）。公式の回避策はない。すぐ上げられなければ、非公式の策として Rack::MethodOverride を外す（_method で PUT / PATCH / DELETE を送るフォームが動かなくなる）か、UTF-8 以外の文字コードを名乗る multipart を手前で拒否する。

2. CISA KEV（11/20 追加）：vCenter CVE-2026-123890・Cisco Expressway CVE-2026-76466・Apache Roller CVE-2026-129448・SAP NetWeaver CVE-2025-42884

  • vCenter（前号の訂正）：前号は「攻撃の報告なし」と書いたが、中国系とみられる集団が 9月初めからゼロデイとして悪用していたと Google（GTIG / Mandiant）が公表した。BeyondTrust Remote Support の CVE-2026-102764 から入り、VMware Directory Service（vmdird）の欠陥で administrator@vsphere.local のセッションを取る。その後、ローカル管理者の作成・VAMI API での SSH の有効化・ESXi のデータへのアクセス。
  • 修正（11/19、VMSA-2026-0009）：vCenter 8.0 U3m、VCF / vSphere Foundation 9.1.1.0200 / 9.0.2.0200。7.0 は延長サポートの契約者だけ。更新に加えて、覚えのない管理者・SSH の有効化の跡を確かめる。
  • Cisco Expressway（CVSS 9.8）：認証なしで root のコマンド実行。修正は 10/21 の X15.5.20（X14 以前は修正版へ移行）。実証コードの公開後、外向きの2台からクラスタの内部の2台へ入られた例が報告された。痕跡：erlang.log の wombat@127.0.0.1、/mnt/harddisk/ 以下の覚えのない .py。
  • Apache Roller は前号のとおり（6.1.6 以上へ）。

3. Linux KVM CVE-2026-99312：AMD のホストで、ゲストがホストのメモリを読み書きできる

  • 入れ子の仮想化（nested）を有効にした AMD のホストが対象。Intel は対象外。ゲストの中の root が必要で、ネットワークだけでは突けない。実証コードは未公開、攻撃の報告なし。評価はカーネルの CVE チームが 8.8、Red Hat は暫定 5.6。
  • 修正：7.3.5 / 6.18.64 / 6.12.118。Debian・Ubuntu・Red Hat（EL9 / EL10）の配布版は記事の時点でまだ。
  • 自分で KVM のホストを持つ場合：cat /sys/module/kvm_amd/parameters/nested が 1 / Y なら、options kvm_amd nested=0 を設定して再起動（入れ子の VM は動かなくなる）。ゲスト側の更新では直らない。

4. pip の同梱 certifi に CVE-2026-133949（CVSS 9.3）

  • pip が同梱する証明書の束に、eMudhra の危殆化した証明書を信頼する内容が残っている件に、11/20 付で CVE が付いた。対象は 26.2.2 未満（26.3.0 は対象外）。修正版の 26.2.2 は 10/20 公開。悪用の報告はない。
  • 先週の pip のダウンロードの約25% はまだ対象の版だったとされる。Dockerfile や CI で pip の版を固定している所、古い仮想環境を見直す。

5. LibreChat 0.8.6：アカウント乗っ取り CVE-2026-54039 ほか

  • 0.7.0〜0.8.5。登録を開けていて（ALLOW_REGISTRATION=true）ソーシャルログインを使う構成で、攻撃者が先に被害者のメールアドレスで登録しておくと、被害者のソーシャルログインがその登録に結び付く（CVSS 8.1、GHSA-wjpf-x42h-cv4m）。0.8.6 へ。
  • 同じ日に、共有エージェントの API キーの露出（CVE-2026-54044）・2段階認証コードの総当たり（CVE-2026-54042）など十数件の CVE が公開された（個別の修正版は未確認）。

6. Windows の未修正の欠陥「FastUnlock」・WhatsApp の修正

  • FastUnlock（11/19 公開）：ロック中の PC に物理的に触れられる人が、ロック画面の回復の手順とナレーターを使い、サインインせずに制限付きのアカウントでプログラムを動かせる。すべての PC で動くわけではない。修正はまだ、攻撃の報告なし。BitLocker を TPM だけで自動解除していると、ロック画面の時点でディスクは読める状態にある。対策は起動時の PIN、持ち出すときはシャットダウンか休止。
  • WhatsApp：CVE-2026-23871（Android、広告返信メッセージの URL の確認不足。2.26.17.4 で修正）、CVE-2026-102769（Android、2.26.35.74 で修正）、CVE-2026-44908（iOS・Mac・Android）。

7. ClickFix の広がり（サイト運営側の話）

  • 7万を超える改ざんサイトが、ブロックチェーン（Polygon）のスマートコントラクトから次のコードを取ってくる JavaScript を埋め込まれている（EtherHiding）。WordPress に悪性のプラグインを入れて居座る例（TRUST#GRAFT）も報告された。
  • 配布サービス「ROMULUS」は、PowerShell から MSI（IconEdit2Turb.msi）を入れ、署名付きの実行ファイルに悪性の DLL を読ませる。通信は DNS over HTTPS。社内の端末では、msiexec の不審な実行と、利用者による PowerShell・「ファイル名を指定して実行」の利用を見張る。
