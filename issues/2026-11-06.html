セキュリティ朝刊

11月6日（金）の朝刊

今日のひとこと：モスカードの番号と残高など約113万件が流出しました。モスカードを使っている人は、残高に身に覚えのない減りがないか確かめてください。

1モスカード約113万件の番号・暗証番号・残高が流出

モスバーガーのモスフードサービスが、カードの管理システムが外部から不正に操作されたと公表しました。

公表は10月23日です。システムを委託している会社の管理システムに、10月14日から18日にかけて不審なアクセスがあり、外部のプログラムを使った不正アクセスと確認されました。流出したのは、モスカード番号（16桁）・暗証番号（6桁）・残高の情報で、113万件あまりです。流出した番号の暗証番号は、会社が強制的に変更したとのことです。店頭やネット注文、「お席で注文」での利用は問題ないと説明されています。

みんながやること
  • モスカードを使っている人は、残高や履歴に身に覚えのない変化がないか確かめる
  • Webでの残高照会やアプリの新規登録ができないときは、モスの問い合わせ窓口へ連絡する

2KDDI・ライフカードでも、委託先や連携先から情報流出のおそれ

ライフネット生命の仕組みを通じて、KDDIが持つ顧客情報が取られた可能性が公表されました。

KDDIは10月30日に、ライフネット生命のシステムの弱点を突かれて、auの生命保険サービスなどの顧客情報（最大約2万2千件）が取得された可能性があると発表しました。氏名・住所・電話番号・メールアドレスなどが対象で、対象の人にはKDDIから順に個別の案内があります。別件で、GMOペイメントゲートウェイは11月2日に、ライフカード向けのサービスで69件の情報が盗まれた可能性があると公表しました。うち3件はVプリカの番号とセキュリティコードを含みます。

みんながやること
  • 該当しそうなサービスを使っている人は、会社からの個別の連絡を待ち、公式サイトのお知らせを自分で開いて確かめる
  • 「確認のお願い」を名乗るメール・SMSのリンクは開かない。カードの利用明細も見ておく

3先日の無印良品・松屋・ノジマの件は、新しい発表待ち

先日お伝えした会員情報の流出について、今朝は新しい発表は見つかりませんでした。

無印良品のアプリ（最大約2,726万件）、松屋のアプリなど（約238万件）、ノジマ（約700万件）は、対象の人への個別の連絡が順に進んでいます。まだ対応していない人は、パスワードの変更と、公式の入り口からの確認をしておいてください。

みんながやること
  • 使っていた人は、パスワードを変え、同じパスワードを使い回した他のサービスも変える
  • メールアドレスや電話番号が知られている前提で、不審なメール・SMS・電話に注意する

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. 委託先・連携先経由の流出：バリューデザイン（モスカード）、ライフネット生命→KDDI、GMOペイメントゲートウェイ（ライフカード向け）、ギフティ

  • モスカード：委託先の管理システムへの外部プログラムによる不正アクセス（10/14〜18）。カード番号・PIN・残高の計 1,133,070 件。流出分の PIN は強制変更。
  • KDDI：ライフネット生命のシステムの一部機能の脆弱性を突かれ、KDDI が持つ顧客情報が取得された（10/23 確認、10/24 に接続を遮断）。GMOPG はライフカード向けの個別機能で不正な行為（10/30 発覚）。ギフティはシステムの脆弱性を突かれて eギフトが不正発行（10/25、損失見込み約5.5億円。個人情報の漏えいは未確認）。
  • やること：外部委託先・連携先の管理画面と API の公開範囲、認証（多要素認証・IP 制限）、アクセスログの監視、発行系の処理の上限と承認の確認。連携先に渡している情報の範囲と、遮断の手順（接続を止める窓口）を決めておく。（ScanNetSecurity の記事を読んだ。会社の原文は未読）

2. 続報：WordPress の wp2shell、Brotli CVE-2026-111497（CISA の期限 11/10）、PHP2Shell、eMudhra

  • WordPress：6.9.5 / 7.0.2 以上（6.8 系は 6.8.6 以上）。CVE-2026-63030（CVSS 9.8）／ CVE-2026-60137。攻撃コードが公開されている。修正版の公開日や CISA への登録日は、資料によって日付が食い違うため、WordPress と CISA の原文で確認する。管理者ユーザーと入っているプラグインに身に覚えのないものがないか確認。
  • Brotli：Node.js は 22.23.4 / 24.22.1 / 26.12.1 以上、.NET 8〜11 は10/25の緊急更新、Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。更新後はプロセスの再起動とイメージの再ビルド。
  • PHP2Shell（CVE-2026-109618 / 109619、悪用あり）：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上。CVE-2026-115560 の回避策は session.upload_progress.enabled=0。
  • eMudhra：今朝も Chrome の emSign ECC Root CA – G3 削除の実施結果と Apple の追加更新は、一次情報では確認できなかった。Apple の案内では、遮断は設定データの自動更新で配信される。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上に。
