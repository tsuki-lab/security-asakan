セキュリティ朝刊

11月20日（金）の朝刊

今日のひとこと：「24時間以内に消えます」「再配達はこちら」と急がせるメールや SMS は、リンクを開かずに公式アプリやブックマークから確かめてください。

1お店の予約や通販の「届け先」の情報が流出。コーセー、通販の発送代行など

化粧品のコーセーは、店頭体験・レッスンの予約システムから、お客さんの情報 28,098件が流出したと発表しました。

対象は直営店「Maison KOSE 銀座」と、閉店した「Maison KOSE 表参道」で予約した人で、氏名・住所・電話番号・生年月日・メールアドレスなどです。また、多くの通販サイトの発送を引き受けている会社「オープンロジ」への不正アクセスでは、届け先の氏名・住所・電話番号に加えて、注文番号や金額なども対象だったと分かり、鹿島アントラーズ（40,844名）や日本テレビ系の通販（10,529件）などが相次いで公表しています。どちらも、パスワードやカード番号が流出したという発表はありません。

みんながやること
  • 心当たりのある人は、各社の公式サイトのお知らせを確かめる（メールのリンクからではなく）
  • 注文内容や住所を知った上での「再配達」「お詫び」「返金」の連絡は詐欺を疑い、SMS やメールのリンクは開かない

発送代行：通販サイトの代わりに、倉庫で商品を保管して発送する会社。買った店とは別の会社が届け先を知っていることがあります。

2サービスの障害に便乗する「急がせる」詐欺メール。AI で文面を磨く道具も

11月12日に起きた Microsoft 365 の大きな障害に合わせて、「保留中のメールが24時間で消えます」と急がせる偽メールが世界中で出回りました。

ニュースになった障害や情報流出は、すぐに詐欺の材料にされます。さらに、生成 AI に文面を書かせ、迷惑メールの判定を通り抜けるまで自動で書き直す道具が、犯罪者向けに売られていることも報告されました。日本語の不自然さで見分けるのは、もう当てになりません。

みんながやること
  • 「期限つきで急がせる」連絡は、まず詐欺を疑う。確かめるのは公式アプリ・ブックマークから
  • ログイン画面に進んでしまったら入力せずに閉じる。入力してしまったら、すぐにパスワードを変え、二段階認証をオンにする

3ブログやお店のサイトを WordPress で作っている人は更新を

サイト作成ソフト WordPress が11月18日に、20件の修正をまとめた新しい版（7.1.5）を出しました。

サイトを乗っ取られるおそれのある欠陥も含まれています。今のところ悪用されたという報告はありません。多くのサイトは自動で更新されますが、止めている場合や古い版のままの場合は手動での更新が必要です。

みんながやること
  • 管理画面の「ダッシュボード」→「更新」を開き、WordPress 本体・プラグイン・テーマを最新にする
  • 制作会社やレンタルサーバーに任せている人は、「更新は済んでいますか」と聞く

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. PHP 8.5.13 / 8.4.28 / 8.3.37 / 8.2.36（11/19）：「phpAfterShell」CVE-2026-126714 ほか

  • 8件を修正（CVSS 9.2 が 7件、8.8 が 1件）。8.6.0 も同日公開。8.1 以前は保守終了。攻撃の報告はなし。10/21 の緊急版（8.5.12 / 8.4.27 / 8.3.36 / 8.2.35）にはこの修正は入っていない。
  • CVE-2026-126714（phpAfterShell）：標準の files セッションハンドラの TOCTOU。セッションの書き込みを途中で止めると新旧のデータが混ざり、次の session_start() がそれをオブジェクトとして読む。試された経路は session.upload_progress（アップロード画面が無くても成立）。コード実行にはアプリ側のガジェットが必要。ログイン状態や CSRF トークンの書き換えにも使える。Redis・DB のセッションはこの欠陥の対象外。
  • ほか：CVE-2026-115560（入力検証）、CVE-2026-129289（リクエスト解釈の食い違い。nginx の fastcgi_keep_conn on、Apache mod_proxy_fcgi の enablereuse=on、HAProxy FastCGI、LSAPI など接続を使い回す構成）、CVE-2026-129496（認証なしでワーカーを落とす／コード実行）、CVE-2026-129481（8.3 以降）、CVE-2026-129182・CVE-2026-129474（8.5 以降）、CVE-2026-129291（FPM ワーカーからの権限昇格）。
  • 修正版では session.upload_progress が既定で無効になった（リリースノートに記載なし）。使っているアプリは更新後に有効へ戻す。
  • やること：修正版へ更新し、コンテナを作り直して再デプロイ。実際に Web を返している PHP の版を確かめる（ディストリのパッケージは版番号を変えずに修正が入ることがある）。更新できないうちは session.upload_progress.enabled = 0 にしてワーカーを再起動（完全な対策ではない）。

2. Ruby 4.0.10 / 3.4.13 / 3.3.14（11/18）：正規表現・文字列処理の欠陥 7件

  • 対象は 4.0.0〜4.0.9、3.4.0〜3.4.12、3.3.13 以前。3.2 以前は保守終了で修正なし。CVE は申請中（GHSA-34m4-m9fh-gqp5、GHSA-7x2q-68qv-6p8x、GHSA-3p8q-wmhx-vm2w ほか）。
  • 5件はコード実行の実証コードがあると開発チームが説明。攻撃の報告はなし。単一バイトの文字コードでの大文字小文字変換のヒープあふれ、文字クラスの積 && を使う正規表現のコンパイルでの二重解放など。
  • やること：Ruby 本体を更新する（gem やフレームワークの更新では直らない）。アプリ・ワーカー・コンテナのイメージを作り直す。利用者の入力から正規表現を組み立てる箇所、外部の文字列の大文字小文字を変える箇所を見直す。

3. nginx 1.31.9 / 1.30.7：HTTP/2 の CVE-2026-123007「nginx2root」ほか4件

  • 1.9.5（2015年）〜1.31.8 のすべてが対象（CVSS 4.0 で 9.2）。HTTP/2 を有効にしたサーバーで、認証なしにワーカーの権限でコード実行（ASLR の無効化または回避が条件。回避して実行できたとの報告が複数ある）。実証コードは公開済み、攻撃の報告はなし。
  • 同時に CVE-2026-123633（HTTP/2）、CVE-2026-123634（SSI・mirror）、CVE-2026-121810（HTTP/3）、CVE-2026-113425（mail proxy）も修正。NGINX Plus は 37.3.0.1 / 37.0.8.1。
  • やること：更新し、reload ではなく再起動かバイナリの入れ替えをする。公式の Docker イメージは修正版のタグあり。すぐ更新できなければ http2 off;（1.25.0 以前は listen から http2 を外す）にし、openssl s_client -alpn h2 で確かめる。CDN の裏でも、オリジンに直接届くなら対象。

4. WordPress 7.1.5（11/18）・Drupal 11.4.13 / 11.3.22 / 10.6.22

  • WordPress：20件の修正。Template Part ブロックの属性による権限昇格（コード実行につながるおそれ）、マルチサイトでサイト管理者が特権管理者を乗っ取れる欠陥、SQL インジェクション 2件、XSS など。4.7 以降の系列にも修正が戻される。
  • Drupal CVE-2026-132165：/core/install.php から認証なしで再インストールを試せる（該当する構成は少ない。実証コードあり）。更新後もインストーラへのアクセスを塞ぐことが勧められている。11.2.x 以前・10.5.x 以前は保守終了。

5. Apache Roller CVE-2026-129448（悪用あり）・VMware vCenter CVE-2026-123890

  • Roller 4.0.0〜6.1.4：XML-RPC が認証前にデシリアライズする（CVSS 9.8）。6.1.6 以上へ。更新までは WEB-INF/web.xml の enabledForExtensions を false にするか /roller-services/xmlrpc の割り当てを消す。管理画面で XML-RPC を切るだけでは足りない。
  • vCenter 8.0・9.0・9.1：VMware Directory Service の認証回避（CVSS 9.8）。回避策なし。攻撃の報告なし。

6. Java4Shell CVE-2026-114938 の続報：実証コードが公開

  • 発見者が、標準構成の Keycloak・Jira・Confluence・Jenkins などで認証なしのコード実行を実証し、コードを公開した。JPCERT/CC は 11/18 時点で悪用を確認していない。
  • Oracle Java SE は 27.0.1.1 / 25.0.5.1 / 21.0.13.1 / 17.0.21.1。OpenJDK の各配布（Temurin・Corretto など）は提供元の更新を確認。外から受け付ける Java のサーバーを先に。

7. Go 1.27.4 / 1.26.11（11/10）

  • 12件を修正。うち 11件は cgo・ビルドツール・コンパイラ・リンカーの欠陥で、細工されたパッケージをビルドするとコードを実行されるおそれ（CVE-2026-97033、CVE-2026-97038 ほか）。CI のツールチェーンとビルド用イメージも更新を。

8. PyPI agent-framework 1.26.1 / 1.26.2 の続報

  • 攻撃者は 1.26.1 が隔離された後に 1.26.2 を公開しており、公開する権限を持ち続けていた。公開できた方法は今も説明されていない。名前に TOKEN・SECRET・AZURE・AWS・GITHUB を含む環境変数と、ほかのプロセス最大300個の環境変数も読む。
  • 保存した鍵を交換しても発行済みのトークンは止まらない。OIDC の権限・フェデレーション資格情報・マネージド ID の役割の割り当ても見直す。安全な版は 1.26.0。
