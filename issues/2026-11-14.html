セキュリティ朝刊

11月14日（土）の朝刊

今日のひとこと：ブックオフやオンライン麻雀「Maru-Jan」の会員だった人は、パスワードを変えてください。同じパスワードを使っているほかのサービスも一緒に。

1ブックオフの会員約638万人分、オンライン麻雀「Maru-Jan」約186万人分のパスワードなどが流出

ブックオフのアプリ・オンラインストア・Web 会員の情報 6,383,279人分が、不正アクセスで持ち出されました。

氏名・生年月日・住所・電話・メールアドレス・ポイントカード番号のほか、パスワードを変換した値も含まれます（カード情報の記載はありません）。また、オンライン麻雀「Maru-Jan」では 1,855,578人分のメールアドレスとパスワードが漏れ、運営会社はほかで使っていないパスワードへの変更を呼びかけています。ポイントサイト「ネットマイル」でも最大約549万人分の氏名・メールアドレスなどが漏れ、サイトを止めています。

みんながやること
  • ブックオフ・Maru-Jan の会員だった人は、パスワードを変える。同じパスワードを使い回しているサービスがあれば、そちらも変える
  • ブックオフやポイントサイトを名乗る「ポイント失効」「ご確認のお願い」などのメール・SMS は、リンクを開かず公式アプリから確かめる

2車に積んだ「偽の携帯基地局」から詐欺の SMS

東京都中央区で、車に積んだ装置から周りのスマホに詐欺の SMS を送っていた疑いで、男が摘発されました。

総務省関東総合通信局と警視庁が11月9日に公表したと報じられています。装置は携帯電話会社の基地局（電波の中継所）になりすまし、近くにいるスマホへ偽サイトに誘う SMS を送るものです。携帯会社や銀行の名前で届いても、本物とは限りません。

みんながやること
  • 携帯会社・銀行・宅配を名乗る SMS のリンクは開かず、公式アプリや自分でブックマークした公式サイトから確かめる
  • iPhone は「不明な差出人」を振り分ける設定、Android は迷惑メッセージの保護をオンにする

3Chrome の更新、まだの人は今日のうちに

11月9日に出た Chrome の更新は、すでに攻撃に使われている欠陥を直すものです。

Chrome は自動で更新されますが、ブラウザを閉じるまで新しい版に切り替わりません。Android の Chrome にも同じ修正が出ています。

みんながやること
  • パソコンは右上のメニュー →「ヘルプ」→「Google Chrome について」を開いて更新し、「再起動」を押す。Android は Play ストアで Chrome を更新
  • iPhone・iPad・Mac も「ソフトウェアアップデート」を確かめる（11月9日に更新あり）

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. eMudhra 続報：Mozilla が emSign Root CA - G1 に TLS の distrust-after（2026-11-16 23:59:59 UTC）

  • Mozilla bug 2089115「Remove email trust and set TLS distrust-after to 2026-11-16 23:59:59 UTC for emSign Root CA - G1」のパッチが承認され NSS に push、RESOLVED FIXED。Websites の信頼と EV は残し、Email の信頼を外す。どの NSS / Firefox の版に入るかは未記載。
  • 11/17 以降に G1 の下で発行された TLS 証明書は、その NSS を使うクライアントで信頼されなくなる見込み。ECC の G3 は 10 月に各社が削除済み。eMudhra は 10/22 に TLS 証明書事業からの撤退を表明している。
  • やること：自社のサイト・API の証明書チェーンに emSign / eMudhra があれば、別の CA で取り直す。

2. N-able N-central：30件超の欠陥と PoC が公開、11/11 に hotfix

  • 研究者が 11/8 に事前連絡なしで公開（Able2Shell）。最重要は認証不要の XXE → RCE の連鎖。N-able は 11/9 にホスト型を停止し、オンプレミスの利用者にもサーバーを一時的にオフラインにするよう案内した。
  • 11/11 に hotfix を公開。悪用は確認されていないが、スキャンは観測されているとする。
  • やること：MSP・社内で N-central を使っていれば hotfix を当て、管理画面を外部に出さない。

3. 国内の大型漏えいの技術的な背景（ScanNetSecurity 11/13 の記事より）

  • ブックオフ（6,383,279人、会員番号ベースで 6,427,735件）：システムの一部のアクセス制御の問題を悪用され、10/4〜6 に持ち出し。パスワードはハッシュ値で保存されていた。認可のテスト（ID を変えて他人のデータが取れないか）を API ごとに。
  • Maru-Jan（1,855,578人）：メールアドレスとパスワード。ネットマイル（最大約549万人）は原因を調査中。丸井グループの委託先 Securitize Japan（最大9,086名、一部は口座番号）。
  • やること：自社サービスで漏えいが起きた場合に備え、パスワードは強いハッシュ（bcrypt / Argon2 など）で保存し、リスト型攻撃への備え（レート制限・二段階認証・漏えいパスワードの拒否）を。

4. 続報：Chrome・Node.js・OpenSSH・Microsoft

  • Chrome 157.0.8103.50/.51（CVE-2026-125350 悪用あり）。Android も 157.0.8103.50。ヘッドレス Chrome・Playwright / Puppeteer のブラウザ、Electron アプリの追従を確認。
  • Node.js 11 月のセキュリティリリース（22.23.5 / 24.22.3 / 26.13.1）、OpenSSH CVE-2026-123158（musl・PAM なしの sshd、10.6p2）、Microsoft 11月の月例（Outlook の CVE-2026-124194 悪用あり）はまだなら優先して。
