セキュリティ朝刊

11月12日（木）の朝刊

今日のひとこと：「お詫び」「確認のお願い」を名乗るメール・SMS・電話は、名前や住所を言い当てられても本物とは限りません。リンクや折り返し番号は使わず、公式サイトや公式アプリを自分で開いて確かめてください。

1ティンパンアレイから延べ約120万件の会員情報が流出した可能性

氏名・住所・電話番号・生年月日・性別・メールアドレスが漏れた可能性があると、親会社のワールドが10月30日に公表しました。

10月17日に業務用のサーバーへ外から入られ、データを抜き出されたとしています。10月28日に気づいてサーバーを切り離しました。会員には準備が整い次第、個別にメールで知らせる予定です。

みんながやること
  • 会員だった人は、会社からのお知らせを公式サイトで確かめる
  • 名前や住所を知っている前提の「お詫び」「返金」の連絡を疑う。リンクは開かない

2JAL の予約システムの委託先で、約9.2万人分の予約情報が見られた形跡

2023年8月10日〜9月23日の便の予約が対象で、約2,000人はパスポート番号やマイレージ番号まで含まれていました。

JAL と日本トランスオーシャン航空が使う予約システムを提供する海外の会社（Amadeus）が不正アクセスを受けました。多くの人は予約番号・氏名・搭乗日・区間で、「見られた形跡」があるという段階です。対象の人には JAL からメールで連絡済みです。

みんながやること
  • その期間に JAL・JTA に乗った人は、JAL からのメールが届いていないか確かめる（届いたメールのリンクではなく、JAL の公式サイトで内容を確認）
  • 「マイルの失効」「予約の変更」「パスポートの確認」を名乗るメール・SMS に注意する

3お店のモバイルオーダー「PICKS」から8,312人分の注文情報が流出

スマホで先に注文して受け取る仕組みで、会員登録せずに注文した人も含めて、氏名・メール・住所・注文の内容などが持ち出されました。

運営する DIRIGIO が10月30日に公表しました。システムの外向けの窓口を通じて入られたとしています。対象の人には、DIRIGIO か、PICKS を使っているお店から順に連絡があります。

みんながやること
  • お店のモバイルオーダーを使った人は、届いた連絡を、お店の公式サイトやアプリで確かめる
  • 注文や返金を名乗るメールのリンクからカード番号を入れない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Node.js 2026年11月のセキュリティリリース：22.23.5 / 24.22.3 / 26.13.1（HIGH 7件）

  • 26.13.1・24.22.3 は 11/10、22.23.5 は 11/11 に公開（配布一覧の日付）。計16件で HIGH は7件。
  • HIGH の主なもの：HTTP/2 の解放後使用（CVE-2026-123866・CVE-2026-123874）、HTTPS の長さ0の TLS 書き込みでヒープの中身が応答に混ざる（CVE-2026-123864）、TLS 1.2 の再ネゴで servername を変えてクライアント証明書の認証を回避（CVE-2026-123872）、HTTP/2 のセッション終了時のアサーションでプロセスが落ちる（CVE-2026-123863）、TLS ハンドシェイク後の未捕捉例外（CVE-2026-126051）、プロトコルエラー時のメモリ・FD リーク（CVE-2026-123865）。
  • MEDIUM には https.Agent が CA の設定をまたいで TLS セッションを再利用し検証を回避（CVE-2026-123877）、プロキシの認証情報がエラーメッセージに出る（CVE-2026-123871）、CA だけの SNI コンテキストで mTLS を回避（CVE-2026-123867）など。llhttp・undici・sqlite も更新。
  • やること：本番・CI・コンテナのベースイメージ、.nvmrc / .tool-versions / engines の固定を更新して再デプロイ。10/21 の Brotli 対応版（22.23.4 / 24.22.1 / 26.12.1）からさらに上げる。20 系以前は修正が出ないので 24 系へ。

2. OpenSSH「SSHole」CVE-2026-123158：CISA が 11/9 に悪用済み（KEV）へ追加

  • PAM を使わない musl 系 Linux（Alpine など）の sshd で、パスワード認証を回避されうる。Portable OpenSSH 10.6p2 で修正（HKCERT・Red Hat などの検索結果の要約で確認）。
  • やること：Alpine ベースのイメージ・VM で sshd を動かしていれば apk upgrade openssh などで更新し、パスワード欄が空のアカウントがないか確認。そもそも本番コンテナで sshd を開けない構成に。
  • 同じ 11/9 の KEV 追加：GPUStack（CVE-2026-102895）、SignalWire FreeSWITCH（CVE-2026-116779）、IBM Aspera Faspex（CVE-2026-123218）。

3. 情報漏洩の技術的な背景（ScanNetSecurity の記事より）

  • PICKS（8,312人）：第三者が API を経由して侵入し、顧客情報を持ち出した。API の認可（他人のデータを取れないか）・レート制限・異常な取得量の検知を見直す。
  • はにくじランド（最大7,622名）：不正なコマンド実行と認証情報の不正利用の形跡。起点の脆弱性は修正済みとされる。サーバーに置いた認証情報（DB・クラウドの鍵）は侵入後に使われる前提で、置き場所と権限を絞る。
  • JAL 委託先 Amadeus（約9.2万人）・九州電力送配電（電力量の情報 4,139件）：委託先・社内システム経由の事案。委託先のシステムで扱うデータの範囲と保存期間（今回は2023年の予約）を見直す。

4. 続報：Microsoft 11月の月例・Brotli・WordPress・PHP・eMudhra

  • Microsoft 11月の月例（Outlook の CVE-2026-124194 は悪用あり）はまだなら最優先。
  • Brotli（CVE-2026-111497、悪用あり）は CISA の期限 11/10 を過ぎた。Node.js は今日の修正版でも Brotli 1.2.1。Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。WordPress（6.9.5 / 7.0.2 以上）と PHP（8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上）も引き続き。
  • eMudhra は今朝も新しい動きは見つからなかった。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上に。
