セキュリティ朝刊

11月26日（木）の朝刊

今日のひとこと：京王・マクドナルド・DHC を名乗る突然のメールや SMS のリンクは開かず、公式アプリやサイトから確かめてください。

1京王電鉄にサイバー攻撃。約1,063万人分の個人情報が流出したおそれ

京王電鉄は、9月にグループのネットワークが「ランサムウェア」（データを人質にする攻撃）を受け、グループの客や取引先 約1,063万人分の個人情報が流出したおそれがあると明らかにしました。

対象は氏名・住所・電話番号・メールアドレスで、一部にはマイナンバー、パスポートの写しや番号、クレジットカード番号、本人確認書類が含まれる可能性があるとしています。賃貸物件の契約者や採用の応募者、従業員など約1万2千人分は、流出が確認されています。

みんながやること
  • 京王グループ（電車・百貨店・ストア・不動産・ホテルなど）を名乗るメール・SMS・電話のリンクは開かず、公式サイトから確かめる
  • クレジットカードの明細に覚えのない利用がないか、ときどき確認する

2マクドナルドのアプリと DHC の通販にも不正アクセス

マクドナルドの公式アプリでは、利用時のスマホの位置情報や購入履歴などが不正に見られ、DHC の通販サイトでは会員 5,096件の登録内容が書き換えられて、不審な注文もありました。

マクドナルドは、氏名・住所・カード情報は含まれないとしています。DHC は、届け先の氏名・住所・電話番号・購入履歴・カード番号の下4桁を見られたおそれがあり、書き換えられた情報は元に戻して対象者に連絡しているとしています。

みんながやること
  • DHC の会員なら、ログインして届け先と注文履歴に覚えのないものがないか確かめる
  • どちらも、各社を名乗る「返金」「確認」の連絡のリンクは開かない。同じパスワードを他のサービスで使っていれば変えておくと安心

3Firefox とメールソフト Thunderbird に更新

Mozilla は 11/24、Firefox と Thunderbird の欠陥（作りの不備）を多数直した更新を出しました。

Thunderbird では、電子署名付きのメールで、実際とは違う人から届いたように見せかけられる欠陥などが直っています。攻撃に使われているという情報は今のところありません。

みんながやること
  • Firefox：メニュー「≡」→「ヘルプ」→「Firefox について」を開き、更新が終わったら再起動する
  • Thunderbird：「ヘルプ」→「Thunderbird について」から同じように更新する

電子署名：メールが本人から届き、途中で書き換えられていないことを確かめるしくみ。

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM・電話には従わず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Drupal「Fail2Install」CVE-2026-132165（CVSS 9.8）：悪用あり・CISA KEV（期限 11/27）

  • 負荷でインストール済みの確認を失敗させ、install.php から SQLite の DB を文書ルートの下に .php として作らせて PHP を実行する。Drupal 8.9・9・10・11 が対象。11/19 19:00 UTC から実際のサイトで悪用。
  • 修正版：11.4.13 / 11.3.22 / 10.6.22。8.9・9・10.5 以前の修正版は記事に無い。回避策の記載はない。更新後、文書ルートに覚えのない .php や SQLite ファイルが無いか確かめる。
  • 同じ 11/24 の KEV：Idunno.AntiCsrf CVE-2026-131914（置き換え）、Optimizely Web Experimentation CVE-2026-132224。

2. Hex.pm（Elixir / Erlang）：CVSS 10.0 の CVE-2026-129514 でサーバー 6台が侵害

  • Erlang 形式のリクエスト本文の解析が認証より前に動き、任意の構造体を装えた。メール・パスワードと API キーのハッシュ・2FA の秘密・非公開パッケージを読まれた可能性がある。レジストリの署名鍵は取り替えておらず、新しい署名の仕組みを入れたクライアントが数日内に出る。
  • 公開パッケージの改ざんは見つかっていない。やること：パスワード変更・2FA の作り直し・mix hex.user auth / rebar3 hex user auth で再ログイン、新しいクライアントが出たら更新、それまで repo.hex.pm 以外のミラーを使わない。
  • 同時に ash 3.38.0、db_connection 2.10.3、flop 0.26.7 / 0.27.3 / 0.28.1 / 0.29.2 の修正。

3. WordPress：WP Connect の6プラグインに裏口（CVE-2026-135202、9.8）

  • Air WP Sync 2.9.1〜2.9.4、WP Sync for Notion 1.7.4、Add-on Brevo for Gravity Forms 2.6.3、Add-On for Contact Form 7 to Airtable 2.5.4、Add-On for Contact Form 7 to Notion 1.6.4、Orders Sync to Airtable for WooCommerce 1.0.2。11/22 に作られ、WordPress.org がプラグインを永久に閉じた。修正版は出ない。
  • 入れていれば削除し、includes/airwp-online.php・tascredit-pay[.]com への通信・uploads のウェブシェル・1時間ごとの WP-Cron・覚えのない DB ユーザーを確認。見つかれば侵害として扱い、パスワードを交換。

4. GeoServer の2件が悪用・Check Point の管理サーバー 24台が侵害

  • GeoServer：CVE-2026-120705（ファイル読み出し 8.6）と CVE-2026-129243（認可回避 8.8）が悪用。同じ修正に固定の署名鍵で管理者を偽れる CVE-2026-129245（9.2）など。3.0.2 / 2.28.6 / 2.27.7 へ。ファイルを読まれた可能性があればパスワードと鍵を取り替える。
  • Check Point：GreyNoise の「GT13」が 10/17〜11/2 に約16か国 22組織で、修正済みの CVE-2026-16232 などを使い、ファイアウォールの DB と社内 CA のファイルを盗み、ポリシーを外した。AI を使った攻撃とみられる。更新・堅牢化と管理画面への到達の制限を。

5. Firefox 161・ESR 153.8 / 115.46、Thunderbird 161 / 153.8（11/24）

  • Firefox 161 は 110件（High 59、Critical なし、サンドボックス回避 13件）。Thunderbird は Critical：OpenPGP 署名メールの差出人の食い違い CVE-2026-136226、細工したメールで IMAP コマンドを送られる CVE-2026-136227。悪用の記載はない。

6. 「IT サポート」を名乗る電話からクラウドの乗っ取り（Unit 42）

  • 電話で認証の不具合を装い、組織に合わせた偽ドメインの中継型フィッシングでパスワード・セッション・MFA の承認を盗み、すぐ自分の MFA 端末と OAuth アプリを登録して Microsoft 365 のデータを抜いて脅す。開発者モードで偽の Chrome 拡張を入れさせる例も。
  • フィッシングに強い認証（パスキー・ハードウェアキー）へ切り替え、MFA の再設定はヘルプデスクが既知の連絡先で本人確認する。新しい MFA 端末・OAuth の同意・メールのルール変更に警告を出す。
