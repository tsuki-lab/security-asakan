セキュリティ朝刊

11月13日（金）の朝刊

今日のひとこと：Chrome を開いて「Google Chrome について」から更新し、再起動してください。iPhone・iPad・Mac も「ソフトウェアアップデート」を確かめましょう。

1Chrome に、すでに攻撃に使われている欠陥。最新版に更新を

Google は11月9日（米国時間）に Chrome の更新を出し、直した欠陥のひとつが実際の攻撃に使われていると明らかにしました。

細工したページを開くだけで悪用されうる種類の欠陥で、Chrome でこうした「修正前から攻撃に使われていた欠陥」が見つかるのは今年8件目です。Chrome は自動で更新されますが、ブラウザを閉じるまで新しい版に切り替わりません。同じ日に Apple も iPhone・iPad・Mac の更新を出しています（近くの Bluetooth 機器から勝手につながれる欠陥などを修正。攻撃に使われたという発表はありません）。

みんながやること
  • パソコンの Chrome は、右上のメニュー →「ヘルプ」→「Google Chrome について」を開いて更新し、「再起動」を押す。Android は Play ストアで Chrome を更新
  • Edge など ほかのブラウザも、同じように更新を確かめる
  • iPhone・iPad は「設定」→「一般」→「ソフトウェアアップデート」、Mac は「システム設定」→「一般」→「ソフトウェアアップデート」

2「ロボットではありません」を装い、コマンドを貼らせる偽画面

大学のサイトが乗っ取られ、見に来た人に「確認のため、この操作をしてください」と偽の画面を出していたことが分かりました。

明治学院大学が11月5日に公表しました。10月16日夜〜19日昼に Mac でサイトを見た人に、ロボットでないことの確認を装って、パソコンに命令文（コマンド）を貼り付けて実行させる画面が出ていました。実行すると、パソコンに悪いプログラムを入れられるおそれがあります。古いまま更新していない iPhone・iPad を狙う仕掛けもありました。ふつうのサイトでも、乗っ取られるとこうした画面が出ます。

みんながやること
  • Web ページに「キーを押して貼り付けて」「ターミナル（Windows は『ファイル名を指定して実行』）を開いて」と言われたら、絶対に従わずにページを閉じる。本物の確認画面はそんなことを求めません
  • もし実行してしまったら、そのパソコンでのネットバンキングなどの利用を止め、別の端末から大事なサービスのパスワードを変える
ことば：コマンド … パソコンに直接出す命令文。貼り付けて実行すると、ふだんの確認画面を通らずにプログラムを動かせてしまう

3メール配信の会社から約8,133万件のメールアドレス、住友生命の健康サービスでも約8万人分が流出

多くの会社がお知らせメールの配信に使う「アララメッセージ」の流出は、重複を除いて81,329,467件のメールアドレスと分かりました。

このサービス経由でメールを受け取っていた人は、自分が知らないうちに対象になっている可能性があります。10月末にはカード会社を装った「利用内容確認のご依頼」などの偽メールが最大約713万通送られました。また、住友生命の健康増進サービス「Vitality」の体験版・企業型など（NTTデータが運営を受託）で、約8万人分の氏名・住所・電話・生年月日・メール・カード番号の一部が漏れました。ヤクルト本社のサイトからも問い合わせなど約4万件が漏れています。

みんながやること
  • カード会社・通販・保険を名乗る「ご確認のお願い」メールは、リンクを開かず、公式アプリや公式サイトを自分で開いて確かめる
  • 会社の福利厚生などで Vitality を使っていた人は、カードの利用明細を確かめる
  • ヤクルトの「たのしい給食」の会員だった人は、同じパスワードを使い回しているサービスのパスワードを変える

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Chrome 157.0.8103.50/.51：CVE-2026-125350（XML の解放後使用）が悪用済み

  • 11/9（米国時間）の Stable 更新。Google は CVE-2026-125350 の攻撃コードが実際に出回っていると告知（今年8件目のゼロデイ）。11/6 に外部から報告。
  • 同じ更新で V8 の型の取り違え（CVE-2026-125344）、GPU の範囲外書き込み（CVE-2026-125348）も修正。Mac は 157.0.8103.50 / .51、Linux は .50。
  • やること：社内端末の Chrome / Chromium 系ブラウザの版を確認。ヘッドレス Chrome・Puppeteer / Playwright のブラウザ、Chromium を同梱する Electron アプリは、それぞれの更新を待って取り込む（同じ部品を使っていれば後追いの更新が出ると見られる）。

2. Apple 11/9 の更新：iOS 27.2.1 / 26.7.3 / 18.7.12、macOS Golden Gate 27.2.1・Tahoe 26.7.3・Sequoia 15.8.3

  • iOS 27.2.1 は CVE 9件とされる。Bluetooth 機器が操作なしでペアリングできる（CVE-2026-113965）、AirPlay のペアリングコードの試行回数制限の回避（CVE-2026-113968）、Bluetooth の解放後使用（CVE-2026-113970）、iMessage のグループで参加前のメッセージが見える（CVE-2026-113961）など。悪用の記載はない。
  • watchOS 27.2.1 / 26.6.1、visionOS 27.2.1 も同日。MDM で管理している端末は配布を。

3. 改ざんサイトの ClickFix 型の偽画面（明治学院大学）

  • 管理者アカウントの不正使用で不正なプログラムを設置され、10/16 夜〜10/19 昼に Mac の閲覧者へ「ロボット確認」を装ってターミナルでのコマンド実行を促す偽画面。iOS / iPadOS 18.5 以前を狙う仕掛けも。
  • やること：CMS・管理画面の多要素認証、使っていない管理者アカウントの削除、ログイン元の制限、ページへの外部スクリプト混入の監視（CSP・改ざん検知）。開発者も「貼って実行」は踏まない。

4. 情報漏洩の技術的な背景（ScanNetSecurity の記事より）

  • アララメッセージ：重複を除き 81,329,467件（「アララメッセージ」経由 78,102,937件、初報の環境 2,842,400件、第3報の環境 3,249,492件）。Web サーバーの脆弱性とシステム環境の問題を悪用されたとする。メール配信 SaaS に預けた宛先リストは、委託先が侵害されれば一括で出る前提で、送る属性を絞る。
  • 住友生命 Vitality（NTTデータ受託、約8万名）：カード番号は一部マスクで保存されていた。ヤクルト本社（約4万件）：会員のパスワードは暗号化で保存。利用者側の使い回し対策を促す告知を。

5. 続報：Node.js・OpenSSH・Microsoft・eMudhra

  • Node.js 11 月のセキュリティリリース（22.23.5 / 24.22.3 / 26.13.1、HIGH 7件）はまだなら今週中に。
  • OpenSSH CVE-2026-123158（musl・PAM なしの sshd、10.6p2 で修正）は CISA の連邦機関向けの期限 11/12 を過ぎた（報道）。Microsoft 11月の月例（Outlook の CVE-2026-124194 は悪用あり）も。
  • eMudhra：Mozilla の移行バグ（2018979）で、RSA の emSign Root CA - G1 の distrust-after などを扱うバグが一度関連付けられ外された。信頼の変更はまだ実施されていない。発行元に emSign / eMudhra があれば別の CA で取り直す。
