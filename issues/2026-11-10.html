セキュリティ朝刊

11月10日（火）の朝刊

今日のひとこと：花キューピットの会員だった人は、パスワードを変えてください。同じパスワードを使い回している他のサービスも一緒に変えるのが安全です。

1花キューピットの会員約424万件の情報が漏えい

「インターネット花キューピット」「ビジネス花キューピット」の会員のログインID、パスワード（読み取りにくくした形）、メールアドレスが外部に漏れました。

10月14〜15日に会社の管理システムへ第三者が侵入し、10月28日に会社が公表しました。カード情報については発表で触れられていません。対象の人には会社からメールで順次連絡があり、全員に届くまで時間がかかる見込みです。

みんながやること
  • 花キューピットを使っていた人は、パスワードを変える。同じパスワードを使い回していた他のサービスも変える
  • 会社を名乗るメールやSMSのリンクは開かず、公式サイトのお知らせから確かめる

2保険・飲食・ポイントのサービスでも漏えいの公表

ソニー生命が扱ったメディケア生命の契約者約38.5万件、デニーズの旧アプリ、ポイントインカムなどでも情報が漏れた可能性があります。

メディケア生命の契約者・被保険者は、氏名・住所・電話番号・証券番号・契約内容などが対象です。ポイントインカムは暗号化されたパスワードを含み、CoinTrade はメールアドレスのみ（約8.8万件）です。いずれも対象者へは会社から個別に連絡があります。

みんながやること
  • 使っていたサービスの公式サイトで、お知らせを自分で確かめる（メールのリンクは開かない）
  • 保険や口座を名乗る電話・メールが急に増えたら、すぐに応じず、公式の窓口にかけ直す

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Brotli CVE-2026-111497：CISA の連邦機関向け期限は今日 11/10（悪用あり）

  • Node.js は 22.23.4 / 24.22.1 / 26.12.1 以上、.NET 8〜11 は10/25の緊急更新、Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。更新後はプロセスの再起動とイメージの再ビルドが必要。
  • すぐ直せないときは、プロキシ／WAF で Content-Encoding: br のリクエストを止めるか、Brotli の復号を無効にする。

2. Node.js：2026-11-11 前後に 22・24・26 系のセキュリティリリースが予告されている

  • oss-security への 11/4 の事前告知による。最高重大度は HIGH、件数・CVE は未公表。日付は目標で、前後することがある（検索結果の要約で確認。原文は未読）。
  • やること：告知が出たら nodejs.org で版を確認し、本番・CI・コンテナを更新して再デプロイできるよう準備しておく。

3. WordPress の wp2shell と PHP2Shell は引き続き先に

  • WordPress：6.9.5 / 7.0.2 以上（6.8 系は 6.8.6 以上）。攻撃コードが公開されている。
  • PHP（CVE-2026-109618 / 109619、悪用あり）：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上。回避策は session.upload_progress.enabled=0。

4. 情報漏洩の技術的な背景（ScanNetSecurity の記事より）

  • デニーズ：旧アプリから新アプリへの移行処理で、第三者が認証情報を不正に作成できた。移行用の経路は、完了後に閉じ、操作ログで本人と第三者を区別できるようにしておく。
  • ポイントインカム：開発環境に置いた過去のテスト用データが閲覧された可能性。本番データを開発環境にコピーしない、置くなら匿名化する。
  • CoinTrade：委託先が使うメール配信システム（アララ）から流出。メール配信の委託先は、権限・API キーの管理と停止時の連絡手順を確認しておく。

5. 続報：eMudhra（証明書）

  • 今朝も新しい動きは見つからなかった。Apple が macOS から AAA Certificate Services ルートを外す予定とする Sectigo の告知の実施は確かめられていない。
  • やること：このルートへの証明書ピン留めがあれば外す。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上に。
