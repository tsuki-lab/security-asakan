セキュリティ朝刊

10月27日（火）の朝刊

今日のひとこと：So-net・plala の会員は公式のお知らせを確認し、「会員情報の確認」を名乗るメール・SMS のリンクは開かないでください。

1So-net・plala の会員情報が約258万件漏えい

ソニーネットワークコミュニケーションズが、会員データベースへの不正アクセスで約258万件の情報が漏えいしたと発表しました。

報道によると、内訳は So-net の会員が約214万件、plala の会員が約44万件で、退会した人の情報も含まれます。漏えいしたのは氏名・電話番号・メールアドレス・ユーザーIDなどで、パスワードの漏えいはないとされています。件数や内容は今後の調査で変わる可能性があります。

みんながやること
  • So-net・plala を使っている（使っていた）人は、会社の公式のお知らせを確認する
  • 「会員情報の確認」「料金の未払い」などを名乗るメール・SMS のリンクは開かず、公式アプリや自分で保存したページから確かめる
  • 同じパスワードを他のサービスでも使っていたら、この機会に変える

2ウェブサイトを動かす仕組み「PHP」の欠陥が、実際に攻撃されています

米国政府機関（CISA）が、PHP の深刻な欠陥2件を「攻撃が確認された欠陥」の一覧に加えました。

PHP は多くのウェブサイトの裏側で動いている仕組みです。欠陥を突かれると、サイトを外から乗っ取られるおそれがあります。修正はすでに公開されていて、直すのはサイトを運営している会社や担当者です。利用者側にできることは多くありませんが、サイトの運営者から「更新のためお待ちください」と案内があったときは、その指示に従ってください。

みんながやること
  • 自分でサイトを運営している人は、使っている PHP を最新に更新する（レンタルサーバーなら管理画面から）
  • 利用しているサービスから「パスワード変更のお願い」が届いたら、公式のサイトから手続きする

3GMO のFX自動売買用サーバーへの不正アクセス、攻撃者が情報を公開

「お名前.com デスクトップクラウド」のFX自動売買用サーバーが狙われ、攻撃者が顧客の情報を公開したと報じられています。

報道によると、対象になりうるサーバーは約2万6千台で、取引口座のログイン情報が取られて不正に使われた可能性があります。GMO は金銭の要求を拒否し、不正な操作による損害は補償する方針と報じられています。公開された情報の範囲は、現時点で確かめられていません。

みんながやること
  • 該当サービスの利用者は、証券・FX の口座と取引ツールのパスワードを変え、ログイン中の端末を切断する
  • 公開された情報を探したり、拡散したりしない

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. PHP2Shell（CVE-2026-109618 / 109619）が CISA KEV に追加

  • CISA が 10/26 に両方を KEV へ追加（連邦機関の対応期限は 10/29）。実際の攻撃と、Apache mod_php での RCE の成功例が報じられている。
  • 修正版は 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35（10/21 公開）。8.1 以前は公式リリースなし（7.4・8.0・8.1 向けは最小限のソース移植が公開）。
  • 完全な対策は更新のみ。session.upload_progress.enabled=0 などの設定は部分的な緩和にとどまる。コンテナはイメージを作り直す（ホストの更新ではイメージ内の PHP は変わらない）。
  • CVE-2026-115560 は修正版待ちのまま（回避策は session.upload_progress.enabled=0）。

2. eMudhra：Chrome の G3 削除は今日（10/27 PT 朝）

  • Chrome は emSign ECC Root CA – G3 を Chrome Root Store から外す予定。G3 の下の証明書を使うサイトは警告が出うる。残りのルート emSign Root CA – G1 も見直し中。
  • Mozilla は 10/20 の NSS 3.131.1 で削除済み。certifi・Homebrew の ca-certificates・Debian / Ubuntu も G3 を外した。
  • macOS の /etc/ssl/cert.pem（curl・git など）は Apple が将来の更新で直すと案内中で、未更新の報道がある。Apple のサポート記事 149555 に、このファイルから該当ルートを外す手順がある（OS 更新で戻ることがある）。
  • 自分のサイトの証明書の発行元に emSign / eMudhra が無いか確認し、あれば別の認証局で取り直す。

3. Node.js 10/21 の修正：Brotli の RCE（CVE-2026-111497）ほか

  • 修正版は 22.23.4 / 24.22.1 / 26.12.1。TLS のホスト名検証2件、DNS の NUL 文字の件も含む10件。21・23・25 系と EOL の 18・20 系に修正なし。
  • 報道により「RCE」と「メモリ破壊と情報漏えいまで確認」で深刻度の表現が割れている。Firefox・.NET など Brotli を使う他の製品にも影響し、Microsoft は .NET の緊急更新を出している。

4. LiteLLM 1.107.0：新しい動きなし

  • 安全な版は 1.106.2。入れた環境は作り直し、鍵とトークンをすべて交換する。10/21 に PyPI と Docker の latest 系を取ったものも対象。

5. 情報漏洩の公表（国内）

  • ソニーネットワークコミュニケーションズ：So-net 約214万件＋plala 約44万件（計約258万件、退会者を含む）。氏名・電話番号・メール・ユーザーID、口座情報16件（日経の見出し）。不正アクセスの確認は 10/23。
  • GMO インターネット：FX自動売買用 VPS（約2万6千台が対象になりうる）。取引口座のログイン情報の不正利用の可能性。攻撃者が 10/27 に情報を公開したと報じられている。
  • ユミルリンク（メール配信サービス）：10/19 公表。メールアドレスを含む情報が延べ約900万件出力されたと試算。委託元の自治体や証券会社にも波及。件数・内容は調査中。
  • 取引先のメール配信・会員基盤の委託先に同種の侵害がないか、委託先の公表を確認する。
