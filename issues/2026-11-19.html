セキュリティ朝刊

11月19日（木）の朝刊

今日のひとこと：銀行やよく使うサービスから「情報流出のお詫び」が届いたら、メールのリンクは開かず、公式アプリやブックマークから内容を確かめてください。

1「お客さん分析」の仕組みからの流出、三菱UFJ銀行や CAMPFIRE などにも広がる

多くの会社がサイトの裏側で使う分析サービス KARTE への不正アクセスで、11月18日に銀行や証券、クラウドファンディングなどの会社も、自社のお客さんの情報が流出したと発表しました。

三菱UFJ銀行は約650万件（性別・年齢・住んでいる地域。氏名や連絡先は含まない）、CAMPFIRE は約582万件（メールアドレスなど）、ウェルスナビは約91万人分などです。多くの会社は、パスワードやカード番号は対象外としています。サービスの再開時期はまだ決まっていません。

みんながやること
  • 使っているサービスのお知らせは、メールのリンクではなく公式サイトや公式アプリで確かめる
  • 「お詫びのポイント」「本人確認のため入力を」というメール・SMS・電話は詐欺を疑う

KARTE：サイトに来た人の行動を分析して、案内やおすすめを出すための仕組み。利用者からは見えにくいところで使われています。

2Chrome に大きな更新。200件以上の欠陥を直した新しい版

Google は11月17日、ブラウザ Chrome の新しい版（158）を出し、204件の欠陥を直しました。

このうち6件は重大なものです。今のところ悪用されたという報告はありませんが、更新は自動では反映されきらないことがあり、Chrome を再起動して初めて新しい版になります。

みんながやること
  • パソコンは Chrome のメニュー →「ヘルプ」→「Google Chrome について」を開き、更新が終わったら再起動する
  • スマホは Google Play・App Store でアプリを更新する

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. PyPI の Microsoft agent-framework 1.26.1 / 1.26.2 に認証情報窃取コード（11/17）

  • Microsoft の正規の公開者アカウントから 33分おいて2版が公開され、PyPI は両方を隔離。公開の時間帯は 11/17 20:35〜21:20 UTC ごろ。月に約19万ダウンロードのパッケージ。公開できた経路は不明。
  • site-packages に .pth（1.26.1 は agent_framework_meta.pth、1.26.2 は af_runtime_diag.pth ＋ af_runtime_diag.py）を置き、import しなくても Python（pip を含む）の起動のたびに実行される。
  • 環境変数、Azure CLI・.npmrc・pip.conf・.netrc・.git-credentials・Docker・Hugging Face・.env などを集め、Azure DevOps・GitHub Actions（1.26.2）の OIDC トークン、Azure のマネージド ID のトークンも要求して webhook[.]site へ送る。
  • やること：1.26.0 に固定し、クリーンな環境で作り直す。該当時間帯にインストールしたホスト・CI ランナーを隔離し、プロキシ・DNS のログで webhook.site/d381fd80-ec62-42ad-8f5c-d1b15103c9bb を探す。別の端末から認証情報を交換し、Azure の ID のサインイン・アクティビティを監査。Azure へデプロイする GitHub Actions のワークフローも確認。

2. CISA KEV に4件追加（11/18）：LiteLLM・Apache Axis・Synology DSM・REDCap

  • LiteLLM CVE-2026-40217：POST /guardrails/test_custom_code のサンドボックスをバイトコードの細工で抜け、proxy のプロセスで任意コード実行（既定の Docker イメージでは root）。対象は 1.81.8 以上 1.83.10 未満、1.83.10 で修正。既定では proxy の管理者の鍵が必要（CVSS 3.1 で 8.8）。低権限から管理者へ上がる欠陥との連鎖も報告されている。10/21 にマルウェア入りで配られた 1.107.0 は避ける。
  • Apache Axis CVE-2026-90436（安全でないリフレクション）：Axis 1.x（1.4 まで）は保守終了で修正版は出ない見込み。Axis2 へ移行するか上流のコミットを当てる。
  • Synology DSM CVE-2024-10441・REDCap CVE-2026-90817：使っていれば最新版へ。

3. Java4Shell CVE-2026-114938：CISA が即時の更新を呼びかけ

  • x86-64 の HotSpot の Base64 デコーダの範囲外書き込み（CVSS 8.1）。細工した入力で JVM がクラッシュし、条件によっては認証なしでコード実行。悪用の報告はまだない。
  • Oracle と OpenJDK が 11/17 に修正。Oracle JDK は 8u513・11.0.33.1・17.0.21.1・21.0.13.1・25.0.5.1・27.0.1.1。Keycloak は「17.0.6 以降の未修正の OpenJDK、21・25 も対象」と説明。
  • やること：同梱・コンテナ内のランタイムも含めて JDK を棚卸しし、配布元（Temurin・Corretto など）の 11 月の版へ。すぐ当てられないときは Base64 入力の大きさを制限し、認証なしで受け付ける口を絞る。

4. Chrome 158（11/17）

  • Windows・Mac 158.0.8127.36/.37、Linux 158.0.8127.36。204件を修正、うち Critical 6件（すべてメモリ安全性）。悪用の報告はなし。XSLT は既定で無効になったので、XSLT に頼るページは確認を。
  • Puppeteer・Playwright などで固定した Chromium を使う CI・コンテナも更新を。

5. KARTE（プレイド）の続報

  • 11/18 に三菱UFJ銀行 約650万件、CAMPFIRE 5,819,779件、ユニフォームネクスト 最大1,701,006件、ウェルスナビ 約91万人、ポケットマルシェ 約95万人、エス・エム・エス 延べ484,504件などが公表。プレイドは漏えいデータの申請企業への提供を続け、再開は未定。
  • やること（利用企業）：外部連携用のシークレットキー・アクセストークンを無効化し、連携先のログを確認。取り込んだ顧客データの項目を洗い出す。
