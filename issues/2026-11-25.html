セキュリティ朝刊

11月25日（水）の朝刊

今日のひとこと：Chrome を最新に更新して、いったん閉じて開き直してください（パソコンも Android も）。

1Chrome に重大な欠陥。更新して再起動を

Google は 11/23、Chrome の重大な欠陥（作りの不備）1件を直した更新を出しました。

攻撃に使われているという情報は今のところありません。ただ、更新は数日から数週間かけて順に届くため、自分で更新を確かめると早く直せます。

みんながやること
  • パソコンの Chrome：右上の「︙」→「ヘルプ」→「Google Chrome について」を開き、更新が終わったら「再起動」を押す
  • Android の Chrome：Google Play ストアで Chrome を更新する

2巨人のファンクラブから約80万件のメールアドレスが流出

読売巨人軍のファンクラブ「CLUB GIANTS」の会員システムが繰り返し攻撃を受け、会員のメールアドレス 約80万7千件が流出したと報じられました。

一部の会員は氏名（約1万7千件）・住所・電話番号・生年月日なども含まれ、274件はパスワードを変換した値（ハッシュ値）も流出しました。攻撃はすでに止めており、悪用は確認されていないとしています。対象の会員にはメールで連絡しています。

みんながやること
  • 巨人や関係者を名乗るメール・電話・SMS のリンクは開かず、公式サイトやアプリから確かめる
  • ファンクラブと同じパスワードを他のサービスでも使っていれば、そちらを変える

3作品投稿の Privatter+ で、他人にパスワードを書き換えられる欠陥

イラストや小説を載せるサービス「Privatter+」で、パスワードの再設定の機能に欠陥があり、他人がパスワードを勝手に変えられる状態だったと公表されました。

11/24 までに13人のアカウントで、パスワードと登録メールアドレスが無断で変えられたことが確認されています。似たような被害は、創作や配信をしている人のアカウントが狙われることもあります。

みんながやること
  • Privatter+ を使っていれば、ログインできるか、登録メールアドレスが自分のものかを確かめ、パスワードを変える
  • ほかのサービスでも、二段階認証（ログイン時の確認コード）やパスキーを使えるところはオンにする

パスキー：パスワードの代わりに、スマホの指紋・顔認証などでログインするしくみ。偽のログイン画面に入力させられる被害を防げます。

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）やパスキーをオンにする
  3. 急がせるメール・SMS・DM・電話には従わず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Chrome 158.0.8127.88 / .89（11/23）：CVE-2026-134401（Critical）

  • Variations の入力検証の欠陥 1件。Windows / Mac は 158.0.8127.88 / .89、Linux は 158.0.8127.88。悪用の記載はない。管理下の端末は配布を待たずに当てる。

2. Azure API Management（Classic 層）：秘密情報を探す攻撃（悪用あり）

  • Microsoft が 11/18 に把握し 11/19 に経路を塞いだ。推奨設定どおりでない Classic 層で管理機能の一部に権限なしで届き、named value の秘密・IdP / OIDC のクライアントシークレット・サブスクリプションキー・管理 API のトークンが読まれたおそれ。v2 層は対象外。CVE なし。
  • やること：11/21 の Microsoft の手順に沿って APIM に置いた秘密情報を洗い出して交換し、それぞれが何に届くかを確かめる。

3. VMware vCenter CVE-2026-123903（CVSS 9.8）：別の vmdir の認証回避

  • 9月から悪用された CVE-2026-123890 とは別物。同じ告知にアーカイブ処理の任意ファイル書き込み CVE-2026-123904（7.5）と DoS 3件。新しい欠陥の悪用の報告はない。
  • 修正版：vCenter 8.0 U3m、VCF / vSphere Foundation 9.1.2・9.0.2.0300、VCF 5.2.5。

4. CISA KEV 11/23：N-able MailAssure CVE-2026-134624・MONAI Label CVE-2026-133968（期限 11/26）

  • MailAssure（9.3）は LDAP 同期の接続確認の SSRF。N-able は 11/16 に侵害を検知し、11/21 に復旧。
  • MONAI Label（9.8）は認証なしのパストラバーサル。AI エージェントを使う攻撃者が大学のサーバーで約11分で悪用し、sitecustomize.py にリバースシェルを書いて root を取った。修正版は各プロジェクトの告知で確かめる。

5. Synology・Roundcube・WHMCS・LiteLLM の修正

  • Synology DSM / BeeStation OS：OAuth API の CVE-2026-120382（9.8、認証なしでファイルの読み書き）。DSM 7.4.1-90080 Update 2 / 7.3.2-86009 Update 6。
  • Roundcube 1.7.7 / 1.6.22（11/23）：12件の修正（スペルチェックの HTTP リクエスト注入、HTML メールの CSS 制限の回避、添付を ImageMagick に渡す問題の再修正など）。1.6 系は今回が最後。
  • WHMCS：認証なしの SQL インジェクション CVE-2026-82981（8.7）は 9.0.10 / 8.13.8。メールキャンペーンの CVE-2026-93700 は、キャンペーンを消してテンプレートのキャッシュを空にしてから更新。
  • LiteLLM：pass-through エンドポイントのコード注入 CVE-2026-136539・MCP のコマンド注入 CVE-2026-136535（どちらも 7.2、管理者級の権限が要る）ほか計6件。修正版は確かめられていない。管理用エンドポイントに届く人を絞る。

6. 電話で「法務」を名乗る標的型の手口（Okta：O-UNC-053 / INCEPTION）

  • 電話で担当者をだまし、legal-<会社名>.com のような偽ページで ID・パスワード・ワンタイムコードを入れさせ、プッシュ通知を承認させて SaaS に入る。10月以降に 70 以上のドメイン（Unit 42）。11/16 から新しいリークサイト「INCEPTION」。
  • パスキーや FastPass などフィッシングに強い認証は破れない。社内の重要な権限から切り替える。

7. 続いている話

  • Ruby「Ruby2Shell」CVE-2026-132825：公開の実証コードは今朝の時点で確認できない。修正は 4.0.10 / 3.4.13 / 3.3.14。gem の更新では直らず、本体の更新と再起動が要る。
  • ScreenConnect CVE-2026-84869（26.6.5）・Idunno.AntiCsrf CVE-2026-131914（置き換え）・GL.iNet の GoodCloud 経由の侵入・React CVE-2026-130165（19.0.9 / 19.1.10 / 19.2.9 / 19.3.1）。
  • eMudhra：Apple は 11/30 に既存の emSign Root CA - G1 の証明書の信頼も終える（eMudhra の告知による）。今朝は新しい発表なし。
  • 情報漏洩：タワーレコード オンラインはログイン情報 約1,021万件（パスワードのハッシュ値を含む）、うち約278万件は氏名・生年月日なども。ミスタードーナツのネットオーダーは 11/15 の侵害で停止中（流出した項目は未公表）。
