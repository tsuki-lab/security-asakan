セキュリティ朝刊

10月28日（水）の朝刊

今日のひとこと：中古車サイト「カーセンサーnet」で販売店に問い合わせたことがある人は、リクルートからの連絡を待ち、「確認のお願い」を名乗るメール・SMS のリンクは開かないでください。

1「カーセンサーnet」の利用者情報が、最大約321万件漏えいした可能性

リクルートが、中古車情報サイト「カーセンサーnet」と販売店向けサービスへの不正アクセスを発表しました。

発表によると、販売店へ問い合わせた利用者について、氏名と住所を中心に最大約321万件の情報が漏れた可能性があります。一部には電話番号・メールアドレスなども含まれます。クレジットカード情報とログインパスワードは含まれないとされ、10月21日の時点で悪用は確認されていません。件数は「可能性のある最大数」で、実際の人数とは異なることがあります。

みんながやること
  • カーセンサーnet で販売店に問い合わせた覚えがある人は、リクルートからの個別の連絡を待つ
  • これに便乗した「情報の確認」を名乗るメール・SMS のリンクや添付ファイルは開かない
  • 気になるときは、公式サイトのお知らせを自分で開いて確かめる

2GMO、FX自動売買用サーバーの不正取引を補償へ

「お名前.com デスクトップクラウド」への不正アクセスで、GMO が損失の補償と、利用者への一律5,000円の見舞金を発表しました。

影響の可能性があるサーバーは2万6千台あまりで、取引口座のログイン情報が取られて不正に使われた可能性があります。補償の申請方法は11月6日までに公式サイトとメールで案内される予定です。

みんながやること
  • このサービスの利用者は、証券・FX の口座と取引ツールのパスワードを変え、ログイン中の端末を切断する
  • 申請の案内は、公式サイトに載ったものだけを信じる（メール内のリンクからは入らない）

3ウェブサイトを動かす仕組み「PHP」の更新は、まだ急ぎです

攻撃が確認された PHP の欠陥について、更新の期限（米国政府機関向け）が明日 10月29日に迫っています。

欠陥を突かれるとサイトを外から乗っ取られるおそれがあります。修正はすでに公開されていて、直すのはサイトの運営者です。利用者側にできることは多くありません。

みんながやること
  • 自分でサイトを運営している人は、PHP を最新に更新する（レンタルサーバーなら管理画面から）
  • 利用しているサービスから「パスワード変更のお願い」が届いたら、公式のサイトから手続きする

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. PHP2Shell（CVE-2026-109618 / 109619）：更新は継続して最優先

  • 修正版は 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35。CISA KEV の連邦機関の期限は 10/29。8.1 以前は公式リリースなし。
  • Amazon の honeypot は公表の4日前（10/17）に攻撃の試行を記録。一方、カナダのサイバーセキュリティセンターは PoC を認めつつ実際の悪用は未確認とするなど、報道は割れている。確実に成立する条件は限られるとの分析もあるが、更新の優先度は変わらない。最も危険なのは mod_php。
  • 完全な対策は更新のみ。コンテナはイメージを作り直す。Palo Alto Networks の PAN-OS・Panorama は全版が対象で未修正と報じられている（10/23 時点）。Fortinet・Cisco は調査中。
  • CVE-2026-115560 は修正版待ち（次の通常リリースで修正予定）。回避策は session.upload_progress.enabled=0。

2. eMudhra：Chrome の G3 削除（10/27 PT）

  • Chrome は emSign ECC Root CA – G3 を Chrome Root Store から外した（予定は 10/27 PT 朝）。Google は残りのルートも調査中。Mozilla は G3 を削除済みで、C1・ECC C3 の退役も進め、G1 は今のところ残す。
  • eMudhra は 10/22 に TLS 証明書事業から撤退する方針を表明。G3 配下に約3万件、約97%は ACME 発行と報じられている。ACME クライアントは別の CA へ切り替える。
  • macOS の /etc/ssl/cert.pem（curl・git など）の更新は、今朝も確認できていない。Apple のサポート記事 149555 に手順がある（OS 更新で戻ることがある）。
  • 自分のサイトの証明書の発行元に emSign / eMudhra が無いか確認する。

3. LiteLLM 1.107.0：新しい動きなし

  • 安全な版は 1.106.2。入れた環境は作り直し、鍵とトークンを交換する。配布は技術者3人の GitHub アカウント（GitHub CLI の OAuth トークンとみられる）経由と LiteLLM が説明している。
  • npm / PyPI の別の新しい侵害は、今朝の検索では確認できなかった。

4. 情報漏洩の公表

  • リクルート（カーセンサーnet・C-MATCH）：最大 3,709,551 件の可能性。販売店へ問い合わせた利用者 最大321万421件、口コミ投稿者 最大5,289件、C-MATCH 登録の販売店関係者 最大48万3,168件（氏名・電話・古物商許認可番号・ログインID。個人事業主は引落口座情報なども）、従業員・委託先関係者 最大1万673件。カード情報とログインパスワードは含まれないとされる。10/17 に検知、10/21 に発表。
  • GMO インターネット：影響の可能性があるサーバー 26,739 件。損失の補償、見舞金5,000円、代替サービスと6カ月無償化。申請案内は 11/6 まで。
  • ラクス「ブラストメール」（子会社ラクスライトクラウド）が 10/21 に不正アクセスを発表したと報じられた。件数・項目は未確認。メール配信の委託先を使っているなら、委託先の公表を確認する。
