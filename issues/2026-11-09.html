11月9日（月）の朝刊

今日のひとこと：新しい大きな発表は少ない朝です。この1〜2週間に公表された会社のサービスを使っていた人は、パスワードを変え、カードの明細を一度見てください。

1今朝は新しい漏えいの発表なし。続いている流出への備えを

新しい発表は見つかりませんでしたが、これまでの流出で届く「なりすましの連絡」はこれからが本番です。

無印良品（アプリ最大約2,726万件、MUJI Card 約109万件）、@cosme 約300万人、クラブツーリズム約432万件、ノジマ約700万件、松屋のアプリなどが、すでに公表されています。会社からの連絡を待つ間に、「カードの確認」「荷物の再配達」「返金」を名乗るメールやSMSが増えやすくなります。

みんながやること
  • 対象の会社のサービスを使っていた人は、会社のお知らせを公式サイトで確かめ、パスワードを変える（同じものを使い回していた他のサービスも）
  • カードの利用明細に身に覚えのない請求がないか見る。メール・SMSのリンクは開かず、公式アプリや公式サイトから確かめる

いつでも効く3つの基本

  1. OS・アプリ・ブラウザは自動更新をオンにして、ときどき再起動する
  2. パスワードはサービスごとに変え、二段階認証（ログイン時の確認コード）をオンにする
  3. 急がせるメール・SMS・DM のリンクは開かず、公式の入り口から確かめる

エンジニア向け

ここから先は、サービスの開発や運用をしている人向けの情報です。前号で既出の話は続報だけ載せています。

1. Brotli CVE-2026-111497：CISA の連邦機関向け期限は明日 11/10（悪用あり）

  • Node.js は 22.23.4 / 24.22.1 / 26.12.1 以上、.NET 8〜11 は10/25の緊急更新、Brotli 本体は 1.2.1 / 1.1.1 / 1.0.10。更新後はプロセスの再起動とイメージの再ビルドが必要（アプリが自前で持つ Brotli は OS の更新では直らない）。
  • すぐ直せないときは、プロキシ／WAF で Content-Encoding: br のリクエストを止めるか、Brotli の復号を無効にする。

2. WordPress の wp2shell と PHP2Shell は引き続き先に

  • WordPress：6.9.5 / 7.0.2 以上（6.8 系は 6.8.6 以上）。攻撃コードが公開されている。管理者ユーザーと入っているプラグインに身に覚えのないものがないか確認。
  • PHP（CVE-2026-109618 / 109619、悪用あり）：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以上。回避策は session.upload_progress.enabled=0。

3. CISA の悪用済みリスト（KEV）：Adobe Commerce/Magento と Ivanti（検索結果の要約ベース）

  • KEV の告知の検索結果に、Adobe Commerce/Magento の CVE-2026-48356 と Ivanti Connect Secure の CVE-2026-111357 の記載があった。告知ページに日付が出ておらず、追加日・期限・修正版は未確認。
  • やること：運用していれば、各社の勧告で修正版を確認して適用する。Ivanti は整合性チェックツール（ICT）の結果と管理者・認証まわりのログも見直す。

4. 続報：eMudhra（証明書）

  • Apple が macOS から AAA Certificate Services ルートを外す予定とする Sectigo の告知（11/2の週）について、実施を確かめられる資料は今朝も見つからなかった。ピン留めをしていなければ影響は想定されていない、と Sectigo は説明。
  • やること：このルートへの証明書ピン留めがあれば外す。発行元に emSign / eMudhra があれば別の CA で取り直す。Rust は webpki-roots を 1.0.10 以上に。
